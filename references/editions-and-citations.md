# 版本、校勘、辨伪与引文规范

> 这份文件解决古代文学综述最容易翻车的地方：**你引的文本可靠吗？你标的出处准确吗？你的注释符合目标刊物吗？**
> 一句话原则：**无版本不引文，无核对不落笔。**

---

## 一、版本学的最小知识

### 1. 常见版本类型

| 类型 | 说明 | 使用时注意 |
|---|---|---|
| **稿本** | 作者手稿或清稿 | 最能反映作者最后意图，但可能涂改、残缺 |
| **抄本** | 人工传抄 | 可能保存早本面貌，也可能累积讹误；注明抄者、年代、藏地 |
| **批校本** | 有批语、校勘、圈点的本子 | 批校者可能是重要学者；区分原文与批校 |
| **刻本** | 木刻版印本 | 注明刊刻年代、刻书地、刻书者、行款、牌记 |
| **活字本** | 活字排印 | 注意活字重排造成的异文 |
| **套印本** | 多色套印 | 注意评点、圈点是否后人添加 |
| **石印本** | 石版印刷 | 晚清民国常见；可能缩印、改字 |
| **影印本** | 原书照相/扫描复制 | 保留原貌，但可能缩印、拼版；注明所据底本 |
| **铅印本** | 近代排印 | 注意排印错误与编辑改动 |
| **点校本** | 新式标点、校勘 | 查底本、参校本、校勘记；不要把整理者的话当古人原话 |
| **笺注本** | 注释、笺释 | 注意注者的解释立场与时代 |
| **汇校本** | 汇集诸本异文 | 适合研究版本谱系；注意汇校者的取舍 |

### 2. 版本谱系

- **祖本**：某一系统最早的版本。
- **原刻/初刻**：初次刊刻。
- **翻刻/重刻**：据前本重新刻印，可能有改动。
- **递修本**：旧版片修补后重印，版片可能有断裂、补刻。
- **足本/节本**：完整本/删节本。
- **孤本/稀见本**：存世唯一或极少。
- **批点本/评点本**：带评点，注意评点者与底本。

### 3. 版本选择：早、全、精、真

- **早**：较早的版本通常更接近原貌，但不绝对——作者可能后来修订，早期刻本也可能出自劣本。
- **全**：完整无缺，避免节本、删本。
- **精**：刊刻精良、校勘严密、错误少。
- **真**：不是伪书、不是误题作者、不是后人重编。

**实际操作**：
1. 先查目录（《中国古籍总目》《中国善本书提要》等）了解版本谱系。
2. 确定**底本**（通常选早、全、精、真兼具者）。
3. 确定**参校本**（不同系统、不同年代、批校本）。
4. 参考**学术整理本**的校勘记，但核对它的底本与取舍。
5. 在综述中写明：底本、参校本、整理者、出版社、版次。

## 二、校勘：陈垣"校法四例"

| 方法 | 做法 | 风险 |
|---|---|---|
| **对校** | 同一书的不同版本对读 | 需要选好底本与参校本 |
| **本校** | 用本书前后文互证 | 前提是本书体例统一 |
| **他校** | 用他书引用、类书、注本、石刻等互证 | 他书可能改动、误引 |
| **理校** | 据文义、音韵、语法、史实推理 | 主观性最强，必须谨慎，不能孤证定案 |

### 校勘记怎么写

- 记录**异文**：某本作某字。
- 说明**依据**：版本、他书、文义。
- 说明**取舍**：从某本，或存疑。
- 不隐瞒反证：如果两说皆通，注明"两存"。

### 异文处理

- 不要为了行文顺畅** silent** 改字。
- 引文若与通行本不同，要说明"据某本"。
- 关键异文可能改变解释，必须在正文或注中交代。
- 不要把**异体字**当**异文**；不要把**避讳字**当原文。

## 三、辨伪与归属

### 1. 辨伪的常见证据

- **目录著录**：历代书目是否著录？何时出现？
- **序跋**：序跋的年代、作者、内容是否自洽？
- **避讳**：避讳字可定年代上限。
- **职官、地理、制度**：是否与所托年代相符？
- **语言、文体、用韵**：是否与作者/时代风格相符？
- **引文**：是否引用了晚出的书？
- **版本**：最早版本何时出现？是否有递藏痕迹？
- **史传**：正史、碑志、年谱是否记载？

### 2. 作者归属

- **外证**：书目、史传、序跋、碑志、同时代人记载。
- **内证**：风格、语汇、用韵、思想、生平经历。
- **注意**：风格判断主观性强，不能单凭"像不像"定案；要有多重证据。
- **存疑**：无法定案时，写"旧题某某作""相传为某某作""著作权存疑"，不要强行归属。

### 3. 伪书也有价值

伪书可以作为**后世接受史、思想史、书籍史**的证据，但不能当作所托时代的可靠史料。综述中要区分：
- "作为某时代的文献"——不可靠；
- "作为某时代人如何想象/伪造古书的证据"——有价值。

## 四、辑佚与系年

### 辑佚

- 来源：类书、总集、古注、方志、石刻、敦煌写本、域外汉籍。
- 每条辑佚要注明**出处、原文、异文、真伪**。
- 注意类书的删节、改编、误题；不要把所有"引某书"都当原文。

### 系年

- 依据：年谱、编年、内证（生平、交游、职官、地理）、外证（史传、碑志、同时人记载）。
- 不同年谱常有异说；要说明采用哪家、理由。
- 不能确定时，用"约作于""疑作于""系年存疑"。

## 五、引文规范：中文人文学科的常规

### 1. 脚注，不是 APA

中国古代文学论文通常用**页下脚注**（当页注），序号用圈码①②③，每页单独排序。具体格式因刊物而异：
- 《文学遗产》系：作者《书名》卷X《篇名》，出版社年份，册次，页码。
- 《历史研究》/《中国社会科学》系：作者：《书名》卷X，版本，页码。
- 学位论文：按学校模板；多数要求脚注 + 文后参考文献。

> **GB/T 7714—2025 是"参考文献著录规则"，不等于所有刊物的脚注格式。** 投稿时以目标刊物最新《来稿技术规范》为准；学位论文以学校模板为准。

### 2. 古籍引文的八个要素

首次引证一部古籍，通常要交代：

1. **作者/编者/整理者**（含朝代，必要时）
2. **书名**（以版权页/卷端为准，主副标题齐全）
3. **卷次**（用该刊规定的数字形式）
4. **篇名**（史书篇题用全称；笔记/诗话可注"某某"条）
5. **版本**（刻本、活字本、抄本、稿本、影印本、点校本等）
6. **出版信息**（出版地、出版者、出版年；刻本则注刊刻年代、刻书者）
7. **册次**（多册书）
8. **页码/叶码**（影印本可用"页a/页b"或"上/中/下栏"）

### 3. 《文学遗产》风格示例

> 以下示例用于说明**要素顺序**，具体标点、数字形式以该刊最新《来稿技术规范》为准。

```text
司马迁《史记》卷四七《孔子世家》，中华书局1959年版，第6册，第1921页。

梁玉绳《史记志疑》卷二九《孔子世家第十七》，中华书局1981年版，第3册，第1119页。

再次引证：《史记》卷四七《孔子世家》，第6册，第1921页。

白居易《白居易集·白氏长庆集》卷三九，中华书局1979年版。
```

**《文学遗产》要点**：
- 古籍卷次用**简式汉字**，如"卷一〇三"；整理本古籍也要注卷次。
- 史书篇题按原书形态用全称，如《史记》中的《刘敬叔孙通列传》不要写成《叔孙通列传》。
- 笔记、诗话等分条编纂的古籍，可注为"'某某'条"。
- 出版单位不用简称（不写"中华书局"为"中华"、不写"上海古籍出版社"为"上古"）。
- 台港澳出版单位不加"台湾""香港""澳门"；如与大陆出版社同名，加引号区分。
- 首次引证详注，再次引证可简写；同一篇文章内保持一致。

### 4. 《历史研究》/《中国社会科学》风格示例

```text
姚际恒：《古今伪书考》卷3，光绪三年苏州文学山房活字本，第9页a。

毛祥麟：《墨余录》，上海：上海古籍出版社，1985年，第35页。

杨钟羲：《雪桥诗话续集》卷5，沈阳：辽沈书社，1991年影印本，上册，第461页下栏。

管志道：《答屠仪部赤水丈书》，《续问辨牍》卷2，《四库全书存目丛书》，
济南：齐鲁书社，1997年影印本，子部，第88册，第73页。

乾隆《嘉定县志》卷12《风俗》，第7页b。

《清德宗实录》卷435，光绪二十四年十二月上，中华书局，1987年影印本，
第6册，第727页。
```

**《历史研究》要点**：
- 作者与书名之间用冒号；出版地后用冒号。
- 卷次可用阿拉伯数字（与《文学遗产》的简式汉字不同，**不要混用**）。
- 影印本注明"影印本"，可标"上册/下册"、"页a/页b"、"上栏/下栏"。
- 地方志：明清方志一般不标作者，书名前冠年号；民国方志冠"民国"。
- 常用基本典籍、官修大型典籍、书名含作者姓名的文集，可不标作者。

### 5. 期刊论文、专著、学位论文

```text
（脚注）
张三《苏轼黄州词编年考》，《文学遗产》2020年第3期，第45—56页。

李四《宋代词体研究》，北京大学出版社2018年版，第120页。

王五《苏轼词版本研究》，博士学位论文，复旦大学，2020年，第33页。
```

```text
（GB/T 7714—2025 参考文献表，顺序编码制示例）
[1] 张三. 苏轼黄州词编年考[J]. 文学遗产, 2020(3): 45-56.
[2] 李四. 宋代词体研究[M]. 北京: 北京大学出版社, 2018: 120.
[3] 王五. 苏轼词版本研究[D]. 上海: 复旦大学, 2020: 33.
```

### 6. 网络资源与数据库

```text
（脚注）
中国国家图书馆《中华古籍资源库》，http://read.nlc.cn/thematDataSearch/toGujiIndex，
2026年10月19日访问。

（GB/T 7714—2025）
[4] 中国国家图书馆. 中华古籍资源库[EB/OL]. [2026-10-19].
    http://read.nlc.cn/thematDataSearch/toGujiIndex.
```

**注意**：
- 网络资源要注明**访问日期**；2025 版标准只对在线资源要求引用日期，纸质书刊不需要。
- 数据库页面可能变动，尽量记录**库名、条目名、检索日期、URL**。
- 古籍数据库的**影像**要注明馆藏与版本；不能只写"来自某数据库"。

### 7. 图像、书影与图表：许可与来源

综述中若使用他人论著中的**书影、版本图版、统计图表、谱系图**，比文字引用更敏感：

- **未经许可不得使用**。古籍影像虽多为公有领域，但**拍摄、整理、排版后的图版**（影印本、数据库的扫描件、研究者的谱系图）通常仍有权利归属。
- 使用必须在**图题或图注中注明来源**（藏书机构、书名版本、或出自某研究者的某书某页），不能只在参考文献里列一条了事。
- 数据库中的影像，注明**库名 + 馆藏 + 版本 + 访问日期**。
- 自己制作的版本谱系图、统计表，要说明**数据来源与制作依据**，并注明"笔者据……编制"。
- 拿不准就用文字描述替代，或者改用公有领域的高清影像自行截取。

### 8. 引文不能代替你的论述

这是综述写作中最隐蔽的一类失范：**用别人的话把自己的论点说完了**，读者看到的只是一串引文和连接词。

- 即使原句已经足够好、你换不出更好的表述，也要**先用自己的话把论点写出来**，再引原文作为支撑。
- 每段引文之后必须有你的**说明或判断**：这条材料是在提供证据、界定概念，还是在标示分歧？
- 检验方法：把正文里所有引号内的内容遮住，剩下的文字**是否仍然读得通、仍然有论点**？如果读不通，说明你在用引文代替论述。

## 六、GB/T 7714—2025：你需要知道的变化

**现行标准**：GB/T 7714—2025《信息与文献 参考文献著录规则》，2025-12-02 发布，2026-07-01 实施，代替 GB/T 7714—2015。

### 主要变化（使用时以标准原文与本单位模板为准）

| 项目 | 2015 版 | 2025 版 |
|---|---|---|
| 术语 | "主要责任者" | "责任者" |
| 图书 | "专著" | "图书" |
| 地图 | "舆图" | "地图" |
| 电子公告 | "电子公告" | "网站、网页" |
| 预印本 | 无专属代码 | 新增 [PP] |
| 西文作者 | 姓全大写，如 SMITH J | 姓首字母大写，如 Smith J |
| 汉语拼音作者 | 姓全大写 | 姓首字母大写，名宜用全称，如 Li Jiangning |
| 引用日期 | 联机文献通常必备 | 仅在线/可能变化的资源需要 |
| 永久标识 | "数字对象唯一标识符（DOI）" | "永久标识符（PID）"，涵盖 DOI、URN 等 |

### 两种标注体系

- **顺序编码制**：正文用 [1][2]，文后按引用顺序排列。
- **著者—出版年制**：正文用（张三，2020），文后按作者字母/拼音排序。

> 中国古代文学论文更常用**脚注**，而非这两种；但学位论文的"参考文献"部分常要求 GB/T 7714。**脚注与文后参考文献可以并存，但不要混用两套体例。**

### 使用提醒

- 先确认学校/期刊要求的是 **2015 版还是 2025 版**；过渡期单位可能仍用 2015 版。
- 文献管理软件（Zotero、EndNote）导出的条目**必须逐条核对**，尤其是古籍、整理本、析出文献、网络资源。
- 2025 版对西文作者大小写、引用日期、文献类型代码有调整；不要直接套用旧模板。
- 标准原文入口：全国标准信息公共服务平台 https://std.samr.gov.cn/ （检索"GB/T 7714—2025"）。

## 七、引文核对：从"看起来对"到"确实对"

### 核对步骤

1. **核对书名/篇名**：以卷端、目录、版权页为准；注意异名、简称、丛书名。
2. **核对作者**：本名、字号、误题、合著、编者、整理者。
3. **核对卷次/回目/折出**：诗文集卷次、小说回目、戏曲折/出、词牌/词题。
4. **核对版本**：刻本/稿本/抄本/点校本/影印本；出版者、出版年、版次。
5. **核对册次/页码/叶码**：多册书的册次；影印本的页a/页b、上/中/下栏。
6. **核对原文**：逐字对照影像或权威整理本；注意异体字、避讳字、脱衍倒讹。
7. **核对标点**：古籍引文的标点是否为整理者所加？引文中的标点是否改变了原意？
8. **核对转引**：是否从二手研究转引？能否找到原书？
9. **核对正文与参考文献**：双向匹配；作者、年份、标题一致。
10. **核对翻译**：海外研究的中译本是否准确？关键概念是否核对原文？

## 八、常见引文错误

| 错误 | 例子 | 修正 |
|---|---|---|
| 书名错 | 《文心雕龙》写成《文心雕龙注》 | 区分原著与注本；注本要注明注者 |
| 篇名错 | 《史记·叔孙通列传》 | 按原书全称《刘敬叔孙通列传》 |
| 卷次错 | 把"卷四七"写成"卷47"（视体例） | 同一篇文章统一数字形式 |
| 页码错 | 用的是 PDF 页码，不是原书页码 | 核对原书/影像页码 |
| 版本错 | 引点校本却标刻本 | 注明底本与整理本 |
| 作者错 | 把整理者当作者 | 区分作者、整理者、笺注者 |
| 张冠李戴 | 把甲诗的句子引成乙诗 | 核对篇名与原文 |
| 转引 | "转引自某某"却当原文 | 找原书；无法找到则明确标"转引自" |
| 电子文本 | 用 OCR 错字当原文 | 核对影像/整理本 |
| 混用体例 | 脚注用《文学遗产》，参考文献用 APA | 统一体例；脚注与文后各按目标要求 |
| 正文/参考文献不匹配 | 正文有、文后无 | 双向核对 |
| 朝代/公元错 | 生卒年、年号、公元换算错误 | 查年表/工具书；注明换算依据 |
| 诗题/词牌/回目错 | 把词牌当词题；回目错配 | 核对原书目录 |
| 引文删改 | 删去转折、限定词，改变原意 | 完整引用或明确用省略号；不改变原意 |
| 伪书/误题 | 把伪书当可靠史料 | 辨伪；标注"旧题""相传" |

## 九、海外研究与翻译的引用

- 引用海外研究，优先用**原文**；用中译本时要注明译者、出版社、版次。
- 关键概念（如 "lyricism"、"intertextuality"、"narrative"）要给出原文，说明你如何翻译、为什么。
- 不要用中译本的术语直接等同于中国古代文论范畴；要做概念史辨析。
- 转引海外研究中的中文材料，要回到中文原书核对。
- 引用日文研究，注意日文汉字与中文简体字的差异；必要时附原文。

## 十、最后一道关：三句话自检

1. **如果把这条引文交给作者本人，他能认出这是他的原话、原版、原页吗？**
2. **如果读者按你的注释去找，能在五分钟内找到同一页吗？**
3. **如果目标刊物编辑抽查一条，你能拿出影像或原书吗？**

> 三条都答"能"，才算完成引文核对。
