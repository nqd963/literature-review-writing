# 示范段落：一段合格的综述正文长什么样

> 规则读了十条，不如看一段成品。本文件用《鵩鸟赋》作年争议这一真实案例，给出**一段合格正文 + 逐句批注 + 反面对照**。
> 落笔前先读第一节，按它的句式与脚注体例写；写完用第二节的六要素逐句自检。
> 材料来自李怡蕾《近四十年来贾谊赋研究综述》（《宁夏师范学院学报》2020 年第 8 期），脚注即按该文文末参考文献表著录。

## 一、示范正文

贾谊《鵩鸟赋》的作年，长期聚讼。赋中"单阏之岁"一语究竟对应哪一年，是全部争议的枢纽：此语一定，作年自明。①

诸家取径不同，结论也随之分歧。田宜弘从贾谊官职的迁转中勾稽线索，推得文帝六年。② 龚克昌依据《史记》《汉书》所载行迹立论，其《旱云赋》作年推断（文帝前元九年，前 171）后为曹道衡《汉魏六朝辞赋》所沿用；③ 张强则把作年问题与贾谊创作历程整体参证，认为辞赋之作当始于贬谪长沙以后。④ 值得注意的是，这三家的分歧并不发生在同一层面：田、龚所争是年份，张强所论是范围。前者若不能解决"单阏之岁"的历法含义，年份之争便无从裁决。

王学军的工作正落在这个关节上。他先指出诸说各有历法依据，分歧的根源在于史籍对汉武帝改历之后太初元年的纪年记载不统一；继而以长沙马王堆三号墓出土文书与传世史料互证，推定"单阏之岁"当指文帝七年，《鵩鸟赋》约作于该年四月。⑤ 出土材料在此并非补充性佐证，而是裁决性依据——它使此前并存的几种历法解释获得了一个可验证的外部标准。

由此可以看清这一问题的推进方式：从正史行事的编年，到职官制度的可推演性，到创作历程的整体参证，再到出土文书的历法裁决，每一次推进都伴随着**证据类型的更换**，而非同类证据的累加。反过来说，早期若干论断之所以反复被推翻，症结常在证据的单薄：曹道衡据《汉书·文帝纪》一条天气记载即定《旱云赋》作于文帝九年，⑥ 在孤证上下断语，其后继者便不得不一再回到起点。作年考证中的许多分歧，表面是解释之争，实质是证据层级之争。

② 田宜弘《贾谊生卒年及其名赋作年考》，《黄石教育学院学报》1989 年第 1 期。
③ 龚克昌《贾谊赋论》，《中州学刊》1985 年第 4 期；曹道衡《汉魏六朝辞赋》，上海古籍出版社 1989 年版，第 36 页。
④ 张强《贾谊赋考论四题》，《文学遗产》2006 年第 4 期。

## 二、逐句批注：这段为什么合格

### 第 1 段（问题化）

| 句子 | 承担的功能 |
|---|---|
| "贾谊《鵩鸟赋》的作年，长期聚讼。" | **问题化**：先告诉读者这里有个悬案，而不是先报人名 |
| "赋中'单阏之岁'一语究竟对应哪一年，是全部争议的枢纽" | **争议的焦点层**：争的不是"作年"这个结果，而是"单阏之岁"的历法含义。把分歧点定位到具体一层，后半段的评判才有着落 |
| "此语一定，作年自明。" | **为何关键**：说明这个争议值不值得花篇幅 |

> 首句主语是**问题**（"作年"），不是人。这是全段最关键的一处。

### 第 2 段（对比诸家）

| 要素 | 落实方式 |
|---|---|
| 谁 + 什么成果 | 田宜弘（期刊论文）、龚克昌（论文）、曹道衡（专著）、张强（论文） |
| 观点 | 文帝六年 / 前元九年 / 贬长沙以后 |
| 依据 | 官职迁转、《史记》《汉书》行迹、创作历程整体参证——**每家都给了依据** |
| 承继／反驳关系 | "后为曹道衡所沿用"——点明继承，不是并列罗列 |
| 我的评价 | "这三家的分歧并不发生在同一层面：田、龚所争是年份，张强所论是范围。" ← **这是段落的主题句，也是本段唯一的判断** |

> 注意：这里没有说"张强认为……曹道衡认为……田宜弘认为……"然后换段，而是**在叙述中穿插关系**（沿用、层面差异），叙述本身就是论证。

### 第 3 段（节点）

- **先写方法**："先指出诸说各有历法依据……继而以马王堆三号墓出土文书与传世史料互证"——交代他怎么做到的。
- **再写结论**：文帝七年四月。
- **再写评价**："并非补充性佐证，而是裁决性依据"——说明**为什么它是节点而不是又一篇**。
- 这一段的判断有具体理由支撑，不是"该研究很有价值"。

### 第 4 段（归纳 + 落到判断）

- **归纳**：把四家的推进概括为一条轨迹——"证据类型的更换，而非同类证据的累加"。这是从若干具体研究抽出的共同倾向，即归纳法。
- **落到判断**：末句"表面是解释之争，实质是证据层级之争"——这是本段（也是整段正文）的结论，可检验、可被反驳。
- **批评点名到具体证据**："据《汉书·文帝纪》一条天气记载即定《旱云赋》作年"——不是"材料支撑不足"这种空话，而是指出**哪一条**证据、**怎么**不足。

### 通篇自查

- [x] 每段首句是论点或问题，不是人名
- [x] 每一家的观点都给了**依据**
- [x] 研究之间的关系写明了（沿用 / 推进 / 裁决）
- [x] 分歧定位到了具体层面（年份 vs 范围；解释 vs 证据层级）
- [x] 批评指名到篇、到条证据
- [x] **全文无"证明"**（用"推定""表明""症结常在"）
- [x] 脚注给出作者、篇名、刊名、年份、期数，专著给页码

## 三、反面对照：同一材料的流水账写法

> 下面是**不合格**的写法。材料完全相同，缺的是判断。

```
关于《鵩鸟赋》的作年，学界有不同看法。龚克昌认为《旱云赋》创作于汉文帝
前元九年。② 田宜弘认为《鵩鸟赋》创作于汉文帝六年。③ 曹道衡也持相同
看法。④ 张强认为贾谊的辞赋创作始于贬长沙以后。⑤ 王学军认为"单阏之岁"
指汉文帝七年。⑥ 总之，关于《鵩鸟赋》的作年问题，学界还存在争议，有待
进一步研究。
```

**它缺了什么：**

| 缺项 | 表现 |
|---|---|
| ❌ 首句是人名 | 全段五个"某某认为"，读者读完不知道这一段在论证什么 |
| ❌ 没给依据 | 每家凭什么这么断？官职迁转？出土文书？正史行迹？一个都没写 |
| ❌ 没写关系 | 曹道衡是沿用龚克昌，不是独立一派；王学军是在裁决而非并列一派——全被抹平了 |
| ❌ 没定位分歧层 | 年份之争与范围之争混在一起，读者看不出谁在回答什么问题 |
| ❌ 没有判断 | "还存在争议，有待进一步研究" = 什么都没说 |
| ❌ 没有批评 | 曹道衡孤证下断语这一最值得指出的问题，被完全略过 |
| ❌ 无脚注页码 | 专著不给页码，无法核查 |

**一句话概括差别**：流水账回答的是"**谁说了什么**"；合格正文回答的是"**这个问题现在走到哪一步、为什么、下一步该往哪走**"。
