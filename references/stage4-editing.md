# 阶段四：编辑与准备终稿（原书第 12–13 章）

> 关键角色转换：此前你是分析、评价别人作品的人；现在你的初稿是被分析评价的对象。
> **第一步：把稿子放一边几天，与它拉开距离。第二步：从"想让读者读懂我的论点"的角度重读。**

> **领域提示**：古代文学论文的引文与注释不是"格式问题"，而是**学术可信度问题**。本阶段先过 [checklist-ancient-literature.md](checklist-ancient-literature.md) 的 60 项领域检查表，再用本章与原书 90 项检查表补漏。著录细则、脚注体例、卷次页码叶码写法见 [editions-and-citations.md](editions-and-citations.md)；不要凭记忆套用 APA。

## 第 12 章：编辑与采纳反馈的二十一条准则

### 准则一：读者永远是对的 ⭐
这是修改过程中最重要的一条。受过教育的读者不理解你的某个观点，沟通就不成立。**为初稿辩解通常适得其反**——去找出读者为什么不懂：分析有误？背景不足？缺过渡？

### 准则二：尽早获取对**内容**的评论
若初稿满是格式错误（拼写、标题错位），导师会先把精力放在这些上而推迟内容评论。先让稿子可读。

### 准则三：先集中精力评论想法
首要任务是确保**你想说的被理解了**；格式问题后面处理。

### 准则四：通过澄清调和矛盾的反馈
评阅人意见相左（一位要你加细节、一位要你删）是常态。你的责任是：① 确认分歧不是因为有人没看懂你的论点；② 与双方讨论达成妥协。

### 准则五：格式意见与体例手册对齐
MLA / Chicago / **APA**（社科与行为科学最常用）/ 各校各系自己的手册。**一旦确定，就要一丝不苟地遵守**。中文语境常为 **GB/T 7714**。

### 准则六：为反馈和修改留足时间 ⭐
**至少做一次较大修订。** 专业作者定稿前常有三稿以上。你要留出从容修订数轮的时间。

### 准则七：把初稿与主题大纲对照
第 9 章的大纲定义了论证路径，检查初稿是否确实遵循了它。

### 准则八：检查结构的平行性 ⭐
读者期待平衡：讨论了缺点就要有优点；支持某立场的论点要有反对论点来平衡。**若确实没有反方研究，要明确说明这一点**（参见准则十的空白点处理）。

### 准则九：避免过度使用直接引语，尤其长引语 ⭐
断章取义的引语传达不了作者原意；解释引语全部内容又会引入无关细节。**转述通常更有效**，且能避免不同作者文风打架造成的混乱（转述仍需引用）。
**很少有人能接受以引语开始一篇综述**——在建立语境之前，读者体会不到引语的预期效果。

### 准则十：避免对反复出现的词语使用同义词 ⭐
学术综述不是创意写作。**必须坚持使用常规术语，即使重复。**
> 混乱："凤凰组……另一组青少年……第 1 组……实验组"（同一组四个叫法）
> 清晰："实验组……对照组"（一贯使用，除非替代表达有助于阐明设计）

### 准则十一：首字母缩略词首次用全称，且不过量
第一次出现必须拼全。不常见的缩略词尽量少用——过多会让人困惑。

### 准则十二：不使用缩写形式
正式学术写作中使用缩写（wasn't / didn't）几乎总是**不恰当**的。

### 准则十三：创造的词语首次使用加引号
表明该词在标准词典中找不到其含义。

### 准则十四：避免俚语、口语和习语
"thing / stuff" → "item / feature / characteristic"；"rise to the occasion" → "address the need"。

### 准则十五：拉丁文缩写只用于括号内，括号外用英文 ⭐

| 缩写 | 含义 | 说明 |
|---|---|---|
| cf. | 比较 | 仅括号内 |
| e.g., | 例如 | 仅括号内 |
| et al. | 以及其他 | **唯一可用于括号外**；"et"后无句号 |
| etc. | 等等 | 仅括号内 |
| i.e., | 即 | 仅括号内 |
| vs. | 对 | 仅括号内 |

### 准则十六：检查是否符合一般写作习惯
1. 句子完整（**大声朗读**——卡住的地方就是要改的句子）
2. 慎用第一人称（可用，但不过度）
3. 避免性别化语言（用复数，或交替使用，或"他或她"）
4. 避免间接结构与被动语态（"在史密斯的研究中……被发现" → "史密斯发现了……"）
5. 0–9 拼写，10 及以上用数字（图表编号、小数与公制单位除外）
6. 名词后跟数字表序列时，名词首字母大写（Item 6, Guideline 16, Chapter 12）
7. 句首是数字时要拼写（"Seventy-five participants..."）——或改写句式让数字不在句首

### 准则十七：拟一个简明的说明性标题 ⭐
标题应明确研究领域并告诉读者你的观点，同时简洁。四条建议：
1. 明确领域，但不过度描述（不要试图把论点每个方面塞进标题）
2. 具体说明你的偏好/方向/范围（例："堕胎的政治：对定性研究的综述"）
3. **避免"可爱"的标题**（双关、典故会分散注意力）
4. **保持简短——经验法则 10 个字左右（上下浮动 3 个字）**

### 准则十八：让文稿对读者友好
1. 拼写检查 + 人工校对（拼写检查抓不出 "see/sea" 类错误）
2. **所有页面编号**（否则评阅人无法引用具体位置）
3. **双倍行距**
4. 1 英寸标准页边距
5. 装订（订书机/可摊平的活页夹；塑料文件夹无法平开）
6. 含标题页（作者、课程、导师、日期），按手册格式居中双行距
7. 至少保留一份备份（云服务 + 硬拷贝）
8. 纸质提交要打印清晰
9. **避免花哨修饰**：彩色高亮（用斜体代替）、混用字号、剪贴画

### 准则十九：所有非自己的文字和想法都必须引用 ⭐
作者-日期法要点：
- 叙述式：Galvan and Galvan (2016)
- 括号内用 `&`：`(Galvan & Galvan, 2016, p. 101)`
- 多个引用用分号分隔：`(Black, 2014; Brown, 2015; Green, 2016)`
- 直接引用必带页码；**转述通常只需作者+年份**
- 二手来源：`(Doe, as cited in Smith, 2016)`——**只有 Smith 进参考文献列表**

### 准则二十：注意避免剽窃 ⭐⭐
六类剽窃（前四类是"换了说法但没标出处"）：
1. 未经引用使用他人的**文字**
2. 未经引用使用他人的**观点**（换词或调序仍算）
3. **引用了但复制原话不加引号**（有出处也照样算剽窃）
4. 借用他人的**短语或句子结构**而不注明
5. 借用他人论文的全部或部分、或用他人的大纲
6. 使用代写服务

补充：剽窃检测软件常会把规范格式的参考文献列表标红——这是误报。可与导师讨论如何排除参考文献后重跑。
后果：**作业/课程不及格、开除；学位论文剽窃可能导致整篇作废并被永久取消研究生资格。**

### 准则二十一：需要时就寻求帮助
写作课、工作坊、写作中心、校对人员。**别指望导师替你编辑格式和行文。**

## 第 13 章：准备参考文献列表（十六条准则）

> 原书以 APA 为准；中文语境通常替换为 GB/T 7714。**骨架一致，细节查你的体例手册。**

1. **考虑使用文献管理软件**（Zotero / EndNote / RefWorks / EasyBib）——可存 PDF、按关键词组织、一键生成格式化条目。**但无论用不用，下列格式问题都要自己核对。**
2. 置于文末"参考文献"大标题下，居中，不加下划线/粗体/斜体/引号。
3. **只包含在正文中实际引用过的文献**——没被引用的不要列。
4. **按第一作者姓氏字母排序**。
5. 所有条目**双倍行距**。
6. **第二行及之后用悬挂缩进**（作者姓氏在左边缘突出）。可用 Word：右键 → 段落 → 特殊格式 → 悬挂缩进（标准半英寸）。
7. 学会用文字处理软件设置悬挂缩进（见上）。
8. **期刊名与卷号用斜体**（期号通常不需要）。
9. **特别注意大小写**——例：APA 中文章标题仅主标题与副标题的首词首字母大写，即使期刊本身全大写。
10. **特别注意标点符号**——例：APA 中年份括号后、条目结尾都要有句号。
11. **不要画蛇添足**——APA 参考文献中页码不用 "p." / "pp."。
12. **在线数据库获取的期刊文章按印刷品引用**，不要当网址引用。数据库自动生成的引文**必须逐条核对**（常会多出期号等冗余）。
13. **在线资源要提供检索日期和完整网址**；无日期用 `(n.d.)`；无作者用机构名。
14. 书籍条目按体例手册设置格式。
15. **用文献管理工具也要交叉检查**生成的引文格式是否正确。
16. **最后逐条对照**：正文每条引用都在列表里？列表每条都在正文被引用？**作者姓名拼写在各处一致？出版年份一致？**

## 建议的改稿轮次

> 下面是**通用五轮**；古代文学请用下一节的**领域六轮**（文献层先于语言层），本节仅作补充。

不要试图一遍解决所有问题。分轮编辑，每轮只盯一类：

1. **轮 1 — 论点与结构**：对照主题大纲；检查论证路径、平行性、连贯性、注释化表述。
2. **轮 2 — 内容与覆盖**：时效性（古代文学按近 10–20 年 + 里程碑，见下节）、里程碑研究、空白点、理论、结论与启示。
3. **轮 3 — 引文与参考文献**：逐条核对，双向匹配，拼写与年份一致。
4. **轮 4 — 语言与格式**：术语一致性、引语、缩略词、俚语、被动语态、数字、标题。
5. **轮 5 — 逐项过 90 项自我编辑检查表**。

# 古代文学领域增强

## 一、改稿轮次（领域版）

古代文学综述的修订顺序应调整，**文献层必须早于语言层**：

1. **轮 1 — 文本与材料**：底本是否交代？引文是否核对原书？版本、卷次、页码/叶码是否准确？作者归属与系年是否有据？
2. **轮 2 — 论证与结构**：是否以问题为经？每一节是否有论点？争议是否写出证据强弱？是否存在"作者+观点"串烧？
3. **轮 3 — 覆盖与学术史**：大陆、港台、海外是否都有交代？里程碑研究是否缺席？近 10–20 年成果是否覆盖？旧文献是否给了理由？
4. **轮 4 — 注释与著录**：体例是否统一？脚注与文末参考文献是否双向匹配？每条转引是否标明？
5. **轮 5 — 语言与格式**：术语、繁体/简体、标点、数字、标题、篇幅。
6. **轮 6 — 逐项过领域 60 项检查表**，再用 90 项补漏。

## 二、注释体例的三条硬规则

1. **一篇论文只用一种体例**。要么全用脚注（《文学遗产》《历史研究》式），要么全文末参考文献 + 文中括注（GB/T 7714 式）。不要混用。
2. **古籍引证必须能定位到卷、篇、页/叶**。只写书名和出版社，等于没引。
3. **转引必须标明**。写"转引自某某书，第 X 页"，并尽可能核对原始出处；不能把转引伪装成直接引用。

### 常用脚注格式（《文学遗产》式，细节以目标刊物最新规范为准）

```text
司马迁：《史记》卷四七《孔子世家》，北京：中华书局，1959年，第6册，第1921页。
（汉）班固：《汉书》卷三〇《艺文志》，北京：中华书局，1962年，第6册，第1701页。
（宋）苏轼：《苏轼文集》卷一《赤壁赋》，孔凡礼点校，北京：中华书局，1986年，第1册，第5页。
（清）姚际恒：《古今伪书考》卷3，光绪三年苏州文学山房活字本，第9页a。
（清）杨钟羲：《雪桥诗话续集》卷5，沈阳：辽沈书社，1991年影印本，上册，第461页下栏。
乾隆《嘉定县志》卷12《风俗》，第7页b。
《清德宗实录》卷435，光绪二十四年十二月上，北京：中华书局，1987年影印本，第6册，第727页。
```

要点：

- **朝代括注**用于常见古籍，视刊物要求取舍；同一篇内统一。
- **卷次**：传统古籍多用汉字（卷四七），民国以后整理本与期刊常可用阿拉伯数字，但**全文统一**。
- **册次**在出版社之后、页码之前。
- **叶码**用 `页 a` / `页 b` / `页 a—b`；影印本可标"上栏/下栏"。
- **出版社**写全称，前加出版地；港澳台与国外出版地照录。
- **整理本**注明整理者（点校、笺注、校注）。
- 再次引证可省出版信息，但仍需卷次、册次、页码。

### GB/T 7714—2025 提示

现行国家标准为 **GB/T 7714—2025**（2025-12-02 发布，2026-07-01 实施，替代 GB/T 7714—2015）。与旧版相关的关键变化包括：责任者著录规则、图书与地图的格式、网站/网页的著录、`[PP]` 等文献类型标识、作者姓名大小写、**仅在线资源需标注引用日期**、PID 的著录。**投稿前以目标期刊的最新征稿规范为准**；标准原文与实施信息见国家标准全文公开系统 <https://std.samr.gov.cn/>。

## 三、逐条核对引文（必须动手，不能凭印象）

对每一条引文，建立一行记录：

| 检查项 | 做法 |
|---|---|
| 书名/篇名 | 与版权页、目录页逐字对照，注意异体字与简称 |
| 作者/编者/整理者 | 与版权页一致；古籍原题与通行署名不同时说明 |
| 版本 | 初版/再版/修订版/影印本/点校本，不能只写出版社 |
| 卷次/篇名 | 核对是否为目标文字所在卷 |
| 册次 | 多册本必查，避免"第 3 册"写成"第 3 卷" |
| 页码/叶码 | 核对单页/双页、a/b 面、上/中/下栏 |
| 引文文字 | 与底本逐字比对；异体字、通假字是否保留 |
| 标点断句 | 古籍引文是否沿用底本断句；改动是否说明 |
| 转引 | 是否标明"转引自"，是否核对原书 |
| 二次引用 | 正文与文末条目是否一致 |

**页码错误是古代文学论文最常见、也最致命的硬伤。** 评阅人只要随手翻一页对不上，整篇的可信度就会崩塌。

## 四、术语与文字的一致性

- **人名**：同一人用同一称法。苏轼/苏东坡/苏子瞻，正文择一，首次出现可括注字号；不要一段一换。
- **书名**：全称与简称统一。首次出现用全称（含卷数），后文可用简称，但要在前言或首次出现处说明。
- **版本名**：宋刻本、元刻本、明嘉靖本、清乾隆武英殿本——朝代 + 刊刻者/年号 + 本，格式统一。
- **文体名**：赋、骈文、古文、时文、传奇、话本、章回小说——不要用现代概念强行替代。
- **繁简**：大陆刊物通常简体，但**引文中的异体字、通假字、避讳字**如需保留，应说明；港台刊物可能要求繁体，投稿前确认。
- **数字**：卷次、篇次按体例；年份、页码用阿拉伯数字；"一二三"用于列举或固定搭配。

## 五、标题与摘要（古代文学版）

**标题**要包含：研究对象 + 问题/角度（+ 时段，如需要）。

- 可取：《从"诗史"到"诗圣"：杜甫接受史上的一个转折》
- 可取：《〈文心雕龙〉"通变"观的版本依据与理论内涵》
- 不可取：《杜甫研究综述》（太泛，没有论点）
- 不可取：《一场美丽的误会——论……》（"可爱"标题，分散注意力）

**摘要**（如需要）四句：问题 → 范围与材料 → 主要判断 → 意义。不要写"本文分为三部分"。

## 六、终稿前的"三遍读法"

1. **逆读**：从结论倒着读每一节，检查每一节是否真的在支撑上一节。
2. **抽读**：只看每段首句，能否连成一条完整论证链。
3. **查读**：随机抽 10 条引文，逐条回原书核对；错 1 条，全篇重查。

## 七、领域终稿红线

- [ ] 没有交代底本/版本就展开阐释。
- [ ] 引文从二手研究转引，却未标明。
- [ ] 卷次、册次、页码/叶码有一处对不上。
- [ ] 全文脚注与文末参考文献体例混用。
- [ ] 只综述大陆研究，港台/海外完全缺席（除非题目明确限定）。
- [ ] 里程碑研究缺席，或列了却没说明为什么重要。
- [ ] 通篇"某某认为"，没有作者自己的判断。
- [ ] 用"证明"描述考证结论。
- [ ] 结论只说"未来需要更多研究"。
- [ ] 正文引用与文末条目不能双向对应。
