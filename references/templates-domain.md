| 大纲编号 | 对应大纲章节 | Ⅲ-2 |

| 出版年份 | 出版/发表年 | 2020 |
| 标题 | 篇名/书名 | 《苏轼黄州词编年考》 |
| 期刊/出版社 | 刊物或出版社 | 《文学遗产》2020年第3期；中华书局 |
| 文献类型 | 专著/期刊论文/学位论文/书评/综述/整理本/古籍 | 期刊论文 |
| 研究对象 | 作家/作品/文体/问题 | 苏轼黄州词 |
| 时段 | 朝代/年份 | 北宋元丰年间 |
| 文体 | 诗/词/文/赋/小说/戏曲/文论 | 词 |
| 核心论点 | 用一句话概括，不用"研究了……" | 黄州词编年应以……为依据 |
| 使用材料 | 版本、年谱、总集、石刻、方志等 | 宋刻本、傅干注、年谱 |
| 研究方法 | 文献学/文体学/阐释/接受史/数字人文 | 版本对校 + 编年考证 |
| 版本/整理者 | 底本、参校本、整理者 | 底本：宋刻本；参校：明钞本 |
| 关键引文 | 可直接引用的短句 | "……" |
| 卷次/篇名 | 引文所在卷次、篇名 | 卷二《……》 |
| 页码/叶 | 原书页码/叶码 | 第12页；第3页a |
| 引文核对 | 已核影像/已核整理本/待核/转引 | 已核影像 |
| 学术史位置 | 奠基/推进/修正/总结/争议一方 | 修正旧说 |
| 与既有研究关系 | 继承/反驳/补充/重复 | 反驳某某（2018） |
| 争议/分歧 | 与谁、争什么 | 系年异说 |
| 证据强度 | 强/中/弱 | 中 |
| 主要局限 | 材料、版本、方法局限 | 未用日藏本 |
| 我的评析 | 你的判断，不是复述 | 论证链完整，但忽略反证 |
| 检索来源/日期 | 库名 + 日期 | CNKI，2026-10-19 |
| 备注 | 其他 | 需补日文研究 |

### CSV 表头（可直接使用）

```csv
编号,大纲编号,作者,出版年份,标题,期刊/出版社,文献类型,研究对象,时段,文体,核心论点,使用材料,研究方法,版本/整理者,关键引文,卷次/篇名,页码/叶,引文核对,学术史位置,与既有研究关系,争议/分歧,证据强度,主要局限,我的评析,检索来源/日期,备注
```

### 填写纪律

- "核心论点"必须是你自己的话，不能复制摘要。
- "使用材料"要具体到版本/总集/年谱，不写"相关文献"。
- "我的评析"要有判断和理由，不写"很有价值"。
- 一条文献可以在多个大纲编号下出现；不要为了"唯一"而删掉它在别处的相关性。
- 关键引文只记**短句**，长段用转述；记下页码/叶，后面省大量时间。

## 二、检索日志（search-log.csv）

```csv
日期,数据库/平台,检索式,字段/限定,命中数,纳入数,排除理由,备注
```

| 字段 | 说明 |
|---|---|
| 日期 | 2026-10-19 |
| 数据库/平台 | CNKI / 中华古籍资源库 / JSTOR / CiNii |
| 检索式 | 完整布尔式 |
| 字段/限定 | 篇名/主题/全文；年份、语言、文献类型 |
| 命中数 | 数据库显示的结果数 |
| 纳入数 | 实际进入笔记表的数量 |
| 排除理由 | 不相关/重复/质量不足/无法获取 |
| 备注 | 权限、异体字、库的覆盖限制 |

> 写"研究空白"时，把这张表的关键行整理成一段检索说明，放在综述开头或空白点之前。

```text

  │    ├─ 清初递修本
  │    └─ 清中期重刻本
  └─ 明钞本
       └─ 清批校本
            └─ 现代点校本（底本：宋刻本；参校：明翻刻、清批校）
```

```csv

```

| 字段 | 说明 |

| 证据类型 | 版本、目录、系年、文本内证、外证、统计 |
| 证据强度 | 强/中/弱 |
| 反证/异说 | 谁反对、有什么反证 |

| 状态 | 已核/待核/需补材料 |

## 九、主题大纲骨架

### 三条硬规则（搭提纲前先看）

1. **三级封顶。** 一级（研究问题）→ 二级（切入角度）→ 三级（方法再分）。**三级以下不再细分**——分类太碎，综述就变成流水账。
2. **堆的形状就是提纲。** 不要先想提纲再找文献，**先把文献分堆**，堆的形状决定了你的章节该怎么切（见 `worked-examples.md` 第七节）。
3. **考证单列。** 系年、版本、辑佚、辨伪、生平交游必须单独设一节，不要散进各章。

### 引言三段式（可直接填空）

```
【底本状况】《XX》著录 X 篇，今存 X 篇，其中《A》《B》《C》为全篇，
           《D》存残篇，《E》存在争议（甲疑为伪作，乙、丙认为非 XX 无疑，
           本文从乙、丙说）。

【统计口径】从 YYYY 年起至 YYYY 年的 XX 年来，有关本研究对象的论文约 XX 篇，
           专著 XX 部。

【本文框架】XXX、XXX 与 XXX 一直是学界关注的重点，本文试从这三个方面
           对相关研究成果进行梳理概括，最后对当前的研究现状作出评价。
```

> 这是古代文学综述的"规矩"：**先给读者一个文献底数**，再谈研究史。社科综述没有这一步。

### A. 专题研究综述（学术史分期式）

```markdown
主题：（研究对象 + 时段 + 文体 + 核心问题，一句话）
核心问题：
本文论点：

一、导言
  A. 问题背景与重要性（具体作品/现象，不用"近年来"）
  B. 概念界定与研究范围（对象、版本、时段、文体；涵盖/不涵盖）
  C. 学术史脉络与本文论证路径

二、文献与版本基础
  A. 原典与整理本（底本、参校本、整理者）
  B. 版本源流、真伪、归属、系年
  C. 出土文献/域外汉籍/稀见资料（若有）
  D. 文献基础的限制

三、学术史回顾（以问题为经，以时间为纬）
  A. 奠基期：问题提出与范式建立
  B. 转型期：理论框架与材料拓展
  C. 拓展期：方法多元与争议展开
  D. 当代：文献集成、文本回归、数字人文
  E. 港台、日本、欧美：另一条问题脉络
  F. 阶段性总结：共识、分歧、范式

四、核心议题与争议
  A. 议题一：各方主张、证据、方法差异
  B. 议题二：……
  C. 争议的方法论根源

五、研究空白与本文切入点
  A. 空白点（附检索策略：库、日期、关键词、语言）
  B. 空白成因
  C. 本文的问题、材料与方法

六、结论
  A. 对研究现状的判断（"似乎可以得出……"）
  B. 对本文研究的启示
  C. 未来研究的具体方向

附录
  A. 检索日志
  B. 版本谱系表
  C. 引文核对表
```

### B. 问题/争议式

```markdown
一、问题的提出
二、争议一：作者/成书/系年
  A. 甲说：主张、证据、推论
  B. 乙说：主张、证据、推论
  C. 分歧的方法论根源
  D. 本文判断
三、争议二：主旨/解释/文体归属
  （同上结构）
四、争议三：版本/文本/接受
  （同上结构）
五、未决问题与本文切入点
六、结论
```

## 十、句式库

### 界定范围

- "本文所论……，指……，不包括……。"
- "为讨论方便，本文将……限定为……，其文本依据是……。"
- "本文以……为底本，参校……，凡引文未特别说明者，均据此本。"

### 概括趋势

- "近二十年来，……研究大致沿着三条路径展开：……、……与……。"
- "从……到……，学界关注的重心由……转向……。"
- "这一阶段的讨论，较之前期更重视……，但在……方面仍有不足。"

### 指出分歧

- "围绕……，学界形成了两种主要解释。一种认为……，另一种则主张……。"
- "分歧的焦点不在……，而在……。"
- "两说所据材料不同：甲说依赖……，乙说则利用……。"

### 评价方法

- "该研究的推进在于……，但其局限也在于……。"
- "作者使用了……，使……得以呈现；然而，……的处理仍显粗略。"
- "这一结论建立在……之上；若……，则结论需要修正。"

### 指出空白

- "就笔者目力所及，尚未见以……为对象的专题研究。需要说明的是，本文的检索范围限于……。"
- "已有研究多集中于……，对……的关注相对不足。"
- "这一空白并非因为问题不重要，而是因为……（材料/方法/学科分工）。"

### 引出本文

- "有鉴于此，本文拟以……为对象，利用……，回答……。"
- "本文不试图全面推翻旧说，而是希望在前人基础上，补充……、修正……。"
- "与既有研究相比，本文的推进主要有三：……。"

### 结论（不用"证明"）

- "根据现有研究，似乎可以得出这样的判断：……。"
- "证据表明……；但这一判断仍受限于……。"
- "尽管多数研究支持……，但……的研究也提示……。在缺乏……的情况下，尚难定论。"

### 未来研究

- "未来的研究可优先利用……（新材/新版本/新数据库），重新检验……。"
- "……群体/文体/地域尚未得到充分研究，值得专题考察。"
- "若能将……与……结合，或可突破当前……的瓶颈。"

## 十一、表格准入标准

综述正文中的表格不宜多。只在以下情况使用：

1. **版本谱系复杂**，文字难以说清。
2. **争议各方材料/方法差异**，表格更清晰。
3. **学术史分期与代表成果**，表格便于对照。
4. **检索范围与结果**，表格便于复查。

使用表格时：
- 每张表必须有**表号 + 说明性标题**。
- 正文必须**介绍并讨论**表格，不能只贴表。
- 表格只放关键项，不要把笔记表原样搬进正文。
- 跨页时表底标"（续）"，下页重复表号 + "（续）"。

## 十二、一页式工作流

```text
1. 写主题说明（对象+时段+文体+问题+版本范围）
2. 建 search-log.csv，先搜 3–5 篇综述/博士论文
3. 反向/正向追踪，建 notes.csv
4. 建 editions.csv（底本、参校本、版本谱系）
5. 建 claims.csv（先填反证）
6. 建学术史地图
7. 选结构（分期/争议/对象/方法/综合）
8. 写大纲，每条文献标大纲编号
9. 写初稿：问题—回应—推进
10. 引文核对表逐条过
11. 领域检查表 + 通用检查表
12. 定稿
```
