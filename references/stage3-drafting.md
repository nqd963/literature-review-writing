# 阶段三：综合与初稿

> 目标产出：**主题大纲 → 初稿**。
> 结构范式、学术史写法、争议处理、结论与未来研究的写法，一律以 [`domain-ancient-literature.md`](domain-ancient-literature.md) 为准；本册只讲**综合与落笔的动作**。
> 落笔前先读 [`model-passage.md`](model-passage.md) 的示范段落，按它的句式与脚注体例写。

---

## 一、综合：从笔记到论点

到这里，最困难的部分（分析、综合、规划论证）其实已经完成。剩下的只是把智力劳动转化为叙述。

### 先定目的和文风

**学术文风要求作者不突出自己，把注意力集中在内容上。**

> 不当："笔者认为贾谊的赋作非常重要，笔者将展示其独特的艺术价值。"
> 得当："贾谊赋在汉赋由骚体向散体大赋过渡中的位置，近年因《鵩鸟赋》作年考订的推进而重新成为问题。"

**学术写作通常慎用第一人称**——让材料和论证说话，而不是"我"。

### 重组笔记，而不是重排笔记 ⭐

**仅仅给出一系列研究注释几乎总是不可接受的。** 那是描述一棵棵树，而你应该描述森林——并且是**一座你自己造出来的新森林**。

做法：建主题大纲勾勒论点 → 在笔记表**新增一列**填入对应大纲编号 → 回到大纲，在各标题旁标注具体参考文献 → **用分析细节充实大纲**（优势与劣势、空白点、研究间关系、主要趋势）。充实后的大纲应有好几页长。

**同一条文献可以在多处出现**——只要它与该处论点相关；不要在综述某处总结一篇后就把它从后续讨论中剔除。

### 综合时要做的四件事

1. **在每个标题下注明不同研究的差异**，并对结果的不一致做出评论与解释（是否因为部分研究更老旧？是否所用材料不同——刻本系统与出土文书？）。
2. **在每个标题中寻找空白点**，并说明它为什么存在。
3. **简要说明相关理论**：先总结初始理论 → 再总结支持它的研究 → 最后指出其尚未被检验的边界。若领域内有相互矛盾的理论，讨论所综述的文献在多大程度上支持各自。
4. **定期总结**：长篇复杂主题需要分阶段总结，末尾再总括一次，为结论铺路。

## 二、落笔的要点

1. **从宽泛的问题领域开始，但避免空泛。** 经验法则是"从一般到特殊"，但"一般"有下限。

   > 空泛："近年来，赋体研究越来越受到学界关注，成果丰硕。"
   > 到位："1980 年以来，贾谊赋研究论文约 96 篇、专著 19 部；其中作年考证、本体阐释与渊源影响三块最为集中。"

2. **开头就说明主题为什么重要**，并**指出为什么某些研究是重要的**（新材料？新版本？改变了问题？）。

3. **区分研究发现和其他信息来源** ⭐。用引导词标明性质：观点或推测用"推测……""有人建议……"；研究发现用"在……的调查中发现……""材料表明……"。

4. **叙述发展历程时时间框架要具体** ⭐。避免"近年来……越来越大"，要给出**具体年份与百分比**；若引用经典或里程碑研究，**说明理由**（开创问题、引领传统、关键术语的原始来源）；**若里程碑研究被重复过，要提及并说明重复的结果**。

5. **结果不一致时分别引用，并推测原因** ⭐。

   > 不可取："各家对作年的判断差异很大，从文帝六年到九年不等。"
   > 可取："以《汉书·文帝纪》天气记载为据者断为文帝九年，以马王堆三号墓出土文书与传世史料互证者断为文帝七年。分歧不在解释，而在证据层级。"

6. **避免冗长、泛泛的参考文献列表** ⭐。

   > 不可取：句末堆一串十七个作者。
   > 可取："许多学者认为贾赋承楚辞传统（e.g., see 龚克昌，1985；曹道衡，1989）。最近的两项研究提供了更可靠的证据（张强，2006；王学军，2018）。其中王学军（2018）以出土文书与传世史料互证，证据最为充分。"

   用 `e.g., see`（例如，见……）表示只列举了部分可能引用；用 `cf.`（比较）表示可对照。

7. **说明边界与空白的理由。** 省略某个相关问题必须给出理由；宣称空白必须**交代检索策略**（哪些库、检索日期、关键词），最好在开头就说明。同时**讨论关于该主题的其他综述**，并说明本文与它们的差别（更新？更全面？结论不同？）。

## 三、让文章连贯

1. **长篇开头提供概述**，明确说明涵盖与不涵盖什么，并**开篇明确你的观点**——用简明的一段告诉读者，是哪一个总体观点在指导你对文献的解释与综合。（注意：这条说的是**什么时候表达**观点，不是什么时候形成——观点应在通读并思考全部文献之后才形成。）

2. **追求清晰连贯，避免注释化表述** ⭐⭐。注释化表述 = 对文章内容的简要概括。把若干注释化表述串起来，只能说明这个主题有哪些研究，**不能为读者组织材料**。
   组织形式应当是**专题性的**，而不是围绕个别作者。一段里引用多项研究，但围绕的是同一个论点。

3. **用子标题与过渡词帮读者追踪论点**（尤其长篇）。子标题的位置要能推进论点。过渡用"第一/第二/最后"，但**不要过度使用**元评论（"本文下一部分将介绍……接下来是……"）——偶尔可以，频繁重复已说过的话就是问题。
   跨学科主题可**分学科综述**。

4. **结尾写出结论并检查连贯性。** 独立综述的结论要明确说明材料如何支撑导言中的主张；学位/期刊论文的综述则引出研究问题。长篇复杂综述先简要总结论证主线，再给结论。
   检查：各部分联系有多紧密？子标题、过渡词与修辞标记（"下一个例子""相关研究""一个反例""最新研究"）都是读者的导航工具。

# 古代文学领域增强

> **本节只保留"写作动作层面"的内容。** 结构范式、学术史写法、争议处理、结论与未来研究的写法，已统一归入 [`domain-ancient-literature.md`](domain-ancient-literature.md) 第五、六、九节，**以那份为准**。下面四项是 domain 文件未覆盖的落笔细节。

## 一、把"版本/史料"写进论证，而不是塞进脚注

古代文学的许多分歧，实质是**底本不同、篇目不同、系年不同、作者归属不同**。综述必须把这一层显性化：

- **先交代文本基础**：本文所据何本？为何用此本？重要异文是否影响结论？
- **遇到结论分歧，先查是不是材料分歧**：两家结论相反，是解释不同，还是所据版本/系年不同？
- **版本谱系要能说清承属**：稿本 → 抄本 → 刻本 → 翻刻 → 点校整理本，哪一环节产生了关键异文。
- **不要用晚出的整理本冒充古本**：引用整理本要注明整理者、出版社、版次；引用影印本要注明所影底本。
- **区别"文献事实"与"文学阐释"**：作者归属、系年、文字异同属可考证的事实层；风格、意旨、影响属阐释层。两层可以互相支持，但不能互相替代。

## 二、句子以问题为主语

注释化表述的根源是句子主语永远是"某某"。改写方法：**让问题、文本、分歧、方法做主语**。

| 弱 | 强 |
|---|---|
| 张三（2010）研究了李白诗歌的用韵。李四（2015）也研究了这个问题。 | 李白用韵的分歧，集中在是否受方言影响。张三（2010）以……为据主张……；李四（2015）则指出…… |
| 王五认为《长恨歌》的主题是爱情。赵六认为是讽喻。 | 《长恨歌》主题之争，实质是对"讽喻"证据的认定不同：王五强调……，赵六则把……读作…… |
| 近年来，数字人文受到关注。 | 2010 年代以来，CBDB、CHGIS 等数据库使……成为可能，但…… |

**每段第一句必须是本段的论点**，不是"某某研究了……"。写完一段后遮住其余句子，只看首句，若能读出这一段在论证什么，才算合格。

## 三、直接引文的纪律

- 古代文学综述引用原典，**必须核对底本**，不能从二手研究转引而不说明。
- 诗、词、曲引文保持原有断句与异体字；如有改动，用校勘符号或注说明。
- 引文超过三行另起 block quote；但**能用一句原文说清的，不要引整段**。
- 引用现代研究者的观点，优先转述；只有定义、关键判断、争议性表述值得直引。
- 每条引文都要问：它是在提供**证据**，还是在提供**权威**？后者通常可以转述。
- 引文不能代替论述：遮住所有引号内的内容，剩下的文字仍须读得通、仍有论点（见 `editions-and-citations.md` 第五节第 8 条）。

## 四、初稿自检（写完一节就做）

- [ ] 这一节的论点能用一句话说出来吗？
- [ ] 段落首句是论点，而不是作者名？
- [ ] 有没有连续三段都是"某某 + 观点"的结构？
- [ ] 版本、系年、作者归属的交代，是否出现在需要它的论证位置？
- [ ] 争议是否写出了"争什么、凭什么、谁更强"？
- [ ] 有没有把"作者的论断"写成"研究的结论"？
- [ ] 有没有出现"证明""毫无疑问""众所周知"？
- [ ] 每一条引文都能回到原书原卷原页吗？
- [ ] 这一节与上一节的衔接句，是否说明了推进关系（而非"接下来"）？

# 中文期刊综述的体裁要件

> 本节内容已按领域规则并入 `domain-ancient-literature.md`（摘要/关键词/引言要件 → 第九节；正文展开手法 → 第五节「两层不要混」）与 `editions-and-citations.md`（图像与图表的许可与来源、引文不能代替论述 → 第五节第 7、8 条）。**请以那两份文件为准。**

通用写作教材（如陈立宏等《关于研究生文献综述撰写的几点建议》，《教育教学论坛》2022 年第 31 期，149–152）给出的条目，是理工科与社科口径的体裁规范。它们在古代文学领域的适用情况如下：

| 条目 | 在古代文学领域 |
|---|---|
| 摘要 200–300 字、关键词 3–5 个 | **适用**，但摘要须能回答"综述的是哪个问题、覆盖哪些材料与时段、判断是什么" |
| 引言三件事（界定领域 / 点出争论 / 说明目的） | **适用**，且须额外交代**文本与版本基础** |
| 正文五种展开手法（循序/论证/分类/对比/归纳） | **降级为内层手法**，外层骨架仍按领域层的五种结构范式选 |
| 参考文献七条纪律 | 大部分与领域层重复（转引不核、当裁判、一手文献）；仅"图表注明来源""引文不能代替论述"为新增，已并入 `editions-and-citations.md` |
| "除经典外尽可能多引近 5 年文献" | **不适用**。古代文学要求经典考证与学术史纵深，"新"不等于"重要" |
