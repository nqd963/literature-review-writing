# 古代文学综述的检索资源与检索方法

> 目标：建立一份**可复查、可覆盖大陆/港台/日本/欧美、原典与研究文献分开**的检索方案。
> 使用前先确认你所在学校图书馆的入口与权限；标注"机构订阅"的资源，通常只能通过校园网、VPN 或图书馆数据库导航访问。

---

## 一、先建立三条检索纪律

1. **原典与研究文献分开搜。** 古籍库解决"文本是什么"，研究库解决"学界说过什么"。两者混在一起搜，必然漏。
2. **每一次检索都留痕。** 日期、库名、检索式、限定条件、命中数、纳入/排除理由。写"研究空白"时，这份日志就是证据。
3. **不要只搜一个库。** CNKI 不能覆盖港台、日本、欧美；古籍全文库不能代替书目库；Google Scholar 不能代替专业目录。**至少三类库交叉：研究文献库 + 古籍影像/全文库 + 书目/工具库。**

| **Web of Science / Scopus / A&HCI** | 全球期刊索引 | 机构订阅 | 查英文研究的引用网络与期刊层级 |
| **CiNii Research（日本）** | 日文论文、图书、学位论文 | 公开 | 日本中国文学研究的主力入口 |

> **CNKI 的使用要点**：先用"篇名/主题"限定，再用"全文"扩展；用"引证文献"看后续研究；用"参考文献"做反向追踪；用"学位论文"找系统梳理；用"报纸"找学术动态。不要只用默认的"全文"检索。

### 最低配置组合（没有校园权限时的起步方案）

**CNKI + 读秀（学位论文与专著章节）+ 中华古籍资源库 + 台湾期刊论文索引 + 国家哲学社会科学文献中心。**

- **CNKI**：大陆研究主力，做正反双向引文追踪。
- **读秀**：补学位论文与专著章节——古代文学的很多关键论断只存在于专著里，期刊库搜不到。
- **中华古籍资源库**（及同类影像库）：核原典、核版本。
- **台湾期刊论文索引 / TCI**：补港台，这是"研究空白"误判最常见的来源。
- **国家哲学社会科学文献中心**：免费入口，无校园权限时的兜底。

> **效率最高的一步**：先找本领域的 **3–5 篇经典论文**，顺着它们的参考文献"顺藤摸瓜"，比盲目换关键词检索快得多（详见第十节"引文追踪"）。

### 古代文学文献的"四条腿"

通用方法论讲的三条路径（顺藤摸瓜／检索法／图书馆）之外，古代文学还要认全四类材料：

1. **基本古籍与整理本**：中华书局点校本、《全宋诗》《全唐文》、作家全集校注本。**引古籍必须注版本与页码**（例：司马迁《史记》，北京：中华书局，1959 年，第 2503 页）。
2. **资料汇编**：《古典文学研究资料汇编》系列 —— 见第四节，写古代评点部分的独门武器。
3. **学术工具书**：年谱、书目提要、选本。**选本本身即研究对象**（选什么、不选什么就是批评史）。
4. **域外与港台汉学**：日本、北美、港台成果最易遗漏，是"研究空白"误判的头号来源（见第五节）。

### 使用古籍库的四条铁律

1. **影像优先于 OCR 文本。** OCR 可用来定位，不可用来定字、定句、定异文。
2. **版本信息优先于书名。** 同一书名可能有宋刻本、明刻本、清刻本、稿本、抄本、石印本、排印本、点校本；不注明版本，等于没有引文。
3. **整理本的话不等于古人的话。** 点校者的校记、笺注、今译、按语，要区分作者原文与整理者判断。
4. **数据库的"全文"不等于"全备"。** 许多库只收常见版本；查不到不等于不存在，要回到书目与馆藏目录。

## 四、书目、目录与工具书

| 工具 | 用途 |
|---|---|
| **《中国古籍总目》** | 查现存古籍的品种、版本、收藏机构 |
| **《中国善本书提要》** | 查善本的版本、行款、递藏、存佚 |
| **《四库全书总目》《续修四库全书总目提要》** | 查历代著作的提要、源流、评价（注意四库馆臣的立场） |
| **《中国丛书综录》** | 查丛书子目、版本、馆藏 |
| **《中国地方志联合目录》** | 查方志版本与馆藏 |
| **《中国历代人物传记资料库》（CBDB）** | 查人物生卒、亲属、仕宦、社会关系 |
| **CHGIS（中国历史地理信息系统）** | 查历史地名、政区沿革、古今对照 |
| **《中国历史地图集》** | 查政区、地名、交通路线 |
| **年谱、编年、系年工具** | 查作家生平行实、作品系年；注意不同年谱的异说 |
| **《中国古典文学研究论文索引》等专题索引** | 查 1949 年以来论文，补数据库回溯不足 |
| **《唐代文学研究年鉴》《宋代文学研究年鉴》《中国古代文学研究年鉴》等** | 查年度研究综述、重要成果、会议动态 |
| **书评、研究综述、会议综述** | 快速摸清领域与争议；再追溯原始研究 |

> **目录书也是史料。** 四库提要、书目题跋、藏书志里常有版本、作者、真伪的关键判断；但要注意编者的立场、时代与著录错误。

### 资料汇编：古代文学综述的独门武器 ⭐

**《古典文学研究资料汇编》系列**（中华书局）按作家/专题分卷，把历代关于该对象的评语、序跋、诗话、笔记材料汇为一编。**这是写"古代评点史"部分最省力的路径，一本书往往能撑起半篇综述。**

- 实例：孔凡礼、齐治平编《古典文学研究资料汇编·陆游资料汇编》——清代部分即收录 158 家评论；李建英《陆游诗研究综述》的古代部分几乎全部评语都出自这一本。
- 同类还有《杜甫卷》《苏轼卷》《陶渊明卷》《李清照卷》《红楼梦卷》等，以及《中国历代文论选》《历代诗话续编》等总集性资料。

**使用要点**：资料汇编是**线索与材料来源**，不是现成结论。引其中的评语要回查原书；汇编的辑录范围、断句与系年也可能有误。

### 选本本身就是研究对象

不要只把选本当"别人的整理成果"。**选什么、不选什么、按什么体例编排，本身就是批评史。**

- 陆游篇在每个朝代末尾都列出该期选本（南宋罗椅《涧谷精选陆放翁诗集》312 首、刘辰翁《须溪精选陆放翁诗集》218 首；清代《宋诗钞·剑南诗钞》《宋十五家诗选·剑南诗选》等五种）。
- 现当代部分单列"选本及校注"一表，共 31 种，并点出钱仲联《剑南诗稿校注》是唯一全注本。
- **综述里讨论选本，等于在讨论接受史。**

## 八、关键词矩阵：不要只搜一个词

把题目拆成五组词，交叉组合：

| 组 | 示例 |
|---|---|
| **对象** | 作家名、字号、谥号、作品名、篇名、文体名、流派名、意象名 |
| **问题** | 考、辨、证、释、论、研究、综述、述评、版本、校勘、系年、编年、辨伪、辑佚、接受、传播、影响、比较 |
| **材料** | 别集、总集、选本、诗话、词话、文话、评点、序跋、碑志、方志、敦煌、简帛、域外汉籍 |
| **方法** | 文献学、文体学、叙事学、阐释学、接受美学、传播学、数字人文、社会网络、地理信息系统 |
| **限定** | 朝代、年份、地域、语言、文献类型 |

### 组合示例

```text
("苏轼" OR "苏东坡" OR "苏子瞻") AND ("黄州" OR "贬谪")
AND ("词" OR "词作") AND ("编年" OR "系年" OR "版本")

("《文心雕龙》" OR "文心雕龙") AND ("通变" OR "文体")
AND ("研究综述" OR "述评" OR "学术史")

("金瓶梅" OR "金瓶梅词话") AND ("版本" OR "作者" OR "成书")
AND ("考证" OR "辨伪")
```

### 检索技巧

- **人名**：本名、字、号、谥号、别称、室名、化名都要试；日文/英文研究可能用拼音或日文汉字。
- **书名**：加书名号与不加都试；简称、异名、丛书名、篇名都要试。
- **异体字/通假字/古今字**：古籍库对字形敏感，必要时用单字或模糊检索。
- **繁简**：大陆库多支持繁简转换，港台/日本库未必；两种都试。
- **字段**：先"篇名/主题"，再"全文"；先精确，后扩展。
- **时间**：先近 10–20 年，再回溯奠基研究；不要一开始就限死五年。
- **文献类型**：期刊、学位论文、专著、书评、会议综述分别搜。

## 九、检索流程（八步）

1. **写主题说明**：研究对象 + 时段 + 文体 + 核心问题 + 版本范围。
2. **找种子**：3–5 篇最新综述/博士论文/核心专著，建立初始书目。
3. **反向追踪**：读种子的参考文献，取交集，形成核心文献集。
4. **正向追踪**：用 CNKI"引证文献"、Google Scholar"Cited by"、JSTOR 等看后续研究。
5. **补研究史**：查年度综述、研究年鉴、书评、会议综述，找出争议与前沿。
6. **补海外**：JSTOR、Project MUSE、Brill、CiNii、港台期刊；中/英/日文分别搜。
7. **回到原典**：确定底本/参校本；查目录、版本、馆藏、影像；核对引文。
8. **补漏与饱和判断**：新增文献不再带来新问题、新证据、新争议时，可认为接近饱和；仍要记录未覆盖的库与语言。

## 十、引文追踪：四种路径

| 路径 | 做法 | 用途 |
|---|---|---|
| **反向** | 读核心文献的参考文献 | 找奠基研究、原始材料 |
| **正向** | 查谁引用了核心文献 | 找后续争论、修正、应用 |
| **横向** | 查同一问题的不同地区/语言研究 | 补港台、日本、欧美 |
| **纵向** | 查年度综述、研究年鉴、书评 | 看趋势、争议、范式变迁 |

**种子选择**：优先选 2–3 部公认的经典专著 + 2–3 篇近十年的研究综述/博士论文。种子太弱，滚雪球会越滚越偏。

## 十一、检索日志：写"空白"的证据

在 `search-log.csv` 中记录：

| 字段 | 说明 |
|---|---|
| 日期 | 检索当天日期 |
| 数据库/平台 | CNKI、中华古籍资源库、JSTOR 等 |
| 检索式 | 完整布尔式或关键词组合 |
| 字段/限定 | 篇名/主题/全文；年份、语言、文献类型 |
| 命中数 | 数据库显示的结果数 |
| 纳入数 | 实际纳入笔记表的数量 |
| 排除理由 | 不相关、重复、质量不足、无法获取等 |
| 备注 | 库的覆盖限制、权限问题、异体字问题 |

**写"研究空白"时的标准句式**：

> 本文检索了中国知网、万方、国家哲学社会科学文献中心、JSTOR、CiNii 等数据库，以"……"为主题词，结合"……"等关键词，检索时间截至 2026 年 10 月；同时查阅了《……》等专著的参考文献与近十年研究综述。就笔者目力所及，尚未见以……为对象的专题研究。需要说明的是，……库对……收录有限，本文的"空白"判断仅限于上述检索范围。

## 十二、覆盖度自检

- [ ] 大陆研究：CNKI/万方/维普/国家哲社文献中心
- [ ] 港台研究：相关期刊与数据库
- [ ] 日本研究：CiNii、日文期刊、全国汉籍数据库
- [ ] 欧美研究：JSTOR、Project MUSE、Brill、A&HCI
- [ ] 中文/英文/日文（至少两种，视题目）
- [ ] 专著/期刊论文/学位论文/书评/综述
- [ ] 原典/整理本/研究文献
- [ ] 近 10–20 年 + 奠基/经典
- [ ] 数据库/纸本/影像
- [ ] 检索日志完整，能复现

> 覆盖度不是"越多越好"，而是**与你的问题相关的主要研究传统都要出现**。如果某一区域确实没有相关研究，要说明原因，而不是假装它不存在。
