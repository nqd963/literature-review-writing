阶段一 · 检索与选题

阶段一：检索与选题

目标产出：候选文献清单 + 主题说明初稿 + 已分组的文献文件夹。 本册只讲通用动作；古籍库、研究数据库、海外汉学入口与检索式见 search-resources.md——那里才是你真正要照着执行的部分。

一、先把检索环境摸清#

大多数一手文献现在都在线上，研究不必再泡书库。但检索环境值得花半天摸清，回报极高：

  1. 确认权限与入口。校园凭证能否访问图书馆资源？校外走 VPN / 代理 / 图书馆链接跳转？这一关不通，后面全白搭。
  2. 找学科馆员，参加一次讲习班。学科馆员知道你所在领域的专属数据库和检索技巧，是性价比最高的一步。
  3. 选一个覆盖面最广的库起步。中文语境通常是 CNKI / 万方 / 读秀，再进学科专库。
  4. 摸清库的功能，试用"高级检索"。第一个动作通常是把默认"全部"改成"文章"；再用年份、文献类型、语言、受众进一步收窄。

检索操作要点#

  • 多词词组加引号："语言发展" 不加引号会被拆成所有单词组合。
  • 布尔运算符：AND 收窄，OR 扩展，NOT 排除。
  • 限定字段：默认搜全文常常爆炸（例：188 篇 → 2210 篇）。**限制在"标题 + 摘要"**往往是最有效的一刀；结果太少时再打开全文检索。
  • 排序：找最新研究用"最新优先"；找里程碑研究用"最早优先"。
  • 随时改关键词——检索是迭代的，不是一次性的。

找齐可用术语：点开任一篇相关文献，看它的主题词 / 关键词字段，那里有规范术语；拿新术语再检索一轮。

二、把"我想研究 X"变成可检索的问题#

先宽后窄#

  1. 写下宽泛的总主题（例："贾谊辞赋"）。它必然过大，这是起点不是终点。
  2. 用一个通用关键词起步，再限制输出。
  3. 结果过多就按副主题重新分类：把结果标题/摘要中反复出现的副主题聚类，再从中选一个。
  4. 结果过少就放宽：放宽日期、打开全文检索、补会议论文与学位论文（质量不如期刊论文，库不负责判断可靠性）。
  5. 必要时扩大文献列表，也考虑未发表的研究——学位论文常因太长或结果与假设不符而从未投稿；可检索学位论文库，或直接联系作者。

捷径：翻课程教科书某章的小标题。教科书常会点出"关于 X 存在争议"，那是天然且边界清晰的初始主题。

三条效率最高的路径 ⭐#

  1. 从最新研究回溯。陌生领域最快的切入法：找一篇最新的相关文章 → 复制它的参考文献列表 → 交叉比对几篇的参考文献取交集 → 得到核心文献集。
  2. 识别里程碑式或经典的研究与理论家。没有里程碑的背景，你就无法理解当前的语境；学位论文漏掉它们会被视为严重缺陷。 - 反复被提及的作者名 → 用该作者名 + 主题词检索，并按"最早优先"排序。 - 作者名检索时不要加引号（会漏掉姓在前的情况）。 - 教科书常会追溯思想史并指出经典研究。
  3. 查询综述文章与方法论反思文章。用"综述 / review"作关键词；综述的参考文献列表远比单篇研究全面。有些期刊专发综述，可指定期刊名检索。

收窄、记下、请教#

  • 写下主题说明的初稿：写成描述性短语，不是论文标题。可以仍然笼统，后面再收窄。
  • 进一步收窄 ⭐：过宽的主题会让你写出肤浅的综述——在各领域间跳跃，无法证明你掌握了文献。好的主题说明会明确写出 1–2 个具体目的。
  • 向导师征求反馈：在读全文之前就问。导师能验证主题，并指出你参考文献中的缺口。

数量与时效#

  • 学期论文：候选 50–150 条，最终引用 5–10 篇以上；学位论文：数百条候选，无硬性下限——标准是全面且最新，而非数量。
  • 时效性（古代文学版）：不是机械的"近 5 年"。以问题史为脉络，近 10–20 年的研究要覆盖，奠基性成果与经典考证不能缺席；引用旧文献要说明它是里程碑、唯一证据、版本依据，还是展示学术史演变。课程论文可聚焦近 10 年，但核心经典仍要读。
  • 古代文学的"全面"还包括：大陆/港台/日本/欧美、中文/英文/日文、原典/整理本/研究文献。覆盖度要求见 search-resources.md。

若题目是导师指定的：尽快开始检索，遇到研究太少或太多立即报告，请导师帮你扩展或收窄。

三、预读、分组、建台账#

预读（prereading）⭐#

不要一上来就逐字精读。预读路线： 标题 → 摘要 → 前几段（作者在此概述问题领域）→ 跳到"方法"之前的段落（这里通常陈述研究目的）→ 浏览全文所有小标题 → 读"讨论"开头几段。

目的只是了解概况、好让你分类。别陷进细节，也别卡在读不懂的地方。

略读还是精读，由关联度决定：

  • 略读：只需了解其重点者——读摘要、结论、图表、参考文献即可。
  • 精读：从略读中挑出的高关联文献——带着批判的眼光读，重点看它依据什么材料、得出什么判断、推论链是否完整，并同步做笔记（用 templates-domain.md 的笔记表）。
  • 古代文学的特殊判据：凡是你打算引用其结论的研究，都必须回到原书核对其所据版本，不能只精读二手研究的转述（见 editions-and-citations.md）。

分组#

电子文献建文件夹，打印件按同样顺序叠放。最常见的做法：先按主题/副主题分组，组内再按时间排序。同一子主题的文章放在一起读，综合会容易得多。

存在空白点就补检索 ⭐#

某些研究领域在你的结果中代表性不足 → 回数据库定向补检。综述中要指出这些一直存在的空白，并详细说明你为寻找相关研究做过哪些不成功的尝试。

建台账 ⭐#

用电子表格（比文档表格灵活，便于插入新类别、跨文档复制粘贴）。先建列标题，建议起步字段：

作者姓名 | 文章标题 | 出版年份 | 期刊 | 分组标识符 | 摘要 | 方法论 | 研究发现 | 评论

按需要扩展：关键术语定义、关键统计数据、所据版本/材料、论证链、方法价值、方法缺陷、证据强度评级、与其他研究的关系、可直接引用的短句 + 页码、我的疑问。

警告：不要把整段摘要复制粘贴进"摘要"栏——那不叫分析，要用你自己的话做简要描述。"方法论/研究发现"栏要用可分类的描述符（公立 vs 私立、证实 vs 证伪、刻本 vs 稿本）。"评论"栏记录：这是里程碑研究吗？它有没有值得放进综述的表格？

两条纪律#

  • 保持灵活性：不同研究差异极大，随时增删字段。
  • 复制到原话必记页码 ⭐：直接引用必须附页码，笔记阶段就记下，能省下后面大量时间。

古代文学检索的五个额外动作#

  1. 拆双线：建两个清单——"原典/版本清单"与"研究文献清单"。前者解决"文本是什么"，后者解决"学界说过什么"。
  2. 查版本谱系：用《中国古籍总目》《中国善本书提要》《四库全书总目》等确认底本、参校本、存佚、藏地；不要拿到一个电子文本就开始引。
  3. 补区域：CNKI 之外，至少查港台期刊、CiNii（日本）、JSTOR/Project MUSE/Brill（欧美）。具体入口见 search-resources.md。
  4. 写检索日志：日期、库、检索式、限定、命中、纳入/排除。写"研究空白"时，这份日志就是你的证据。
  5. 核对引文：任何准备写进笔记的原文，标明"已核影像/已核整理本/待核/转引"。转引必须回查；无法回查要明确标注。

做到这五条，再进入阶段二。否则后面会出现"观点很多、文本很虚"的典型问题。

阶段二 · 分析文献

阶段二：分析文献

目标产出：逐篇笔记表 + 版本表 + 论点—证据表 + 争议表。 本册的"领域评估准则"是古代文学专用的评价标准，优先于下面的通用要点；通用要点只在领域准则没有覆盖时补充。

领域评估准则（古代文学优先）#

1. 版本可靠性#

  • 作者用的是哪个版本？底本、参校本、整理者、出版社、版次是什么？
  • 是否交代了版本谱系？是否知道该版本在谱系中的位置？
  • 强：使用早期善本/权威整理本，交代底本与参校本，关键异文有校记。
  • 弱：只写书名不写版本；用来源不明的电子文本；把晚出通行本当宋本。

2. 文本真实性与作者归属#

  • 是否讨论真伪、误题、后人增补、辑佚来源？
  • 作者归属的外证与内证是否充分？是否只凭"风格像"？
  • 强：目录、序跋、避讳、职官、地理、语言、版本多重证据。
  • 弱：把伪书当可靠史料；把"旧题"当"确证"；无视作者归属争议。

3. 年代与系年#

  • 成书/写作年代依据是什么？采用哪家年谱？异说如何处理？
  • 强：内证 + 外证 + 年谱互证，异说并列说明。
  • 弱：只凭单一说法；把"约"当"确年"；用后世记载推前代之事。

4. 材料层级#

  • 用的是原典、总集、类书、注本，还是二手研究？
  • 总集/类书可能删改、误题；注本可能误释；二手研究可能转引。
  • 强：回到原典/早期版本，区分材料层级。
  • 弱：只读研究文献；把类书引文当原书；把注者的解释当原文。

5. 论证链#

  • 从材料到结论的每一步是否成立？有没有跳步、循环论证、以偏概全？
  • 强：材料—推理—结论链条完整，关键步骤有反证检验。
  • 弱：先有结论再找材料；用"显然""众所周知"跳过论证；孤证定案。

6. 引文核对#

  • 引文是否核对原书/影像？页码/卷次/篇名是否准确？
  • 强：逐条核对，注明版本与页/叶。
  • 弱：转引不核；电子 OCR 直接引用；引文删改改变原意。

7. 方法适配#

  • 所用的理论/方法是否适合研究对象？是否说明概念来源与适用边界？
  • 强：方法服务于问题，能解释文本，能处理反例。
  • 弱：理论套用；术语堆砌；用西方概念直接覆盖中国范畴。

8. 学术史位置#

  • 该研究是在回应谁？推进了什么？被谁修正？
  • 强：明确对话对象，说明继承/修正/补充。
  • 弱：自说自话；重复旧说；不提反方。

9. 阐释力与反证#

  • 解释能否覆盖更多文本细节？能否说明例外？
  • 强：解释力强，主动处理反证与异说。
  • 弱：只挑有利证据；把例外归为"例外"而不解释。

10. 覆盖度#

  • 是否覆盖大陆/港台/日本/欧美相关研究？是否使用多语言材料？
  • 强：主要研究传统都出现，语言/材料限制有说明。
  • 弱：只引大陆；只引近五年；海外研究缺席。

证据强度速判#

强度 特征
强 原典 + 多版本对校 + 可靠系年 + 完整论证链 + 回应反证
中 原典 + 单一版本/部分二手材料 + 论证基本成立，但反证处理不足
弱 仅二手研究/网络文本/孤证/以论代史/概念套用

记住："证据强度"不是"结论你同不同意"。你可以不同意一个强论证，也可以同意一个弱论证；综述要评价的是论证质量，不是立场。

逐篇分析的通用要点#

领域准则之外的补充动作，按这个顺序读每一篇：

  1. 关键术语要有明确定义。 不同研究者的定义差异，本身可能就是结论差异的原因。有重大分歧时单列一栏记定义；优先引用权威定义；在综述开头给出关键术语的定义通常是好做法，并提供对比性术语（同时定义"集体主义"与"个人主义"）效果更好。
  2. 区分论断和证据 ⭐。常见错误是把作者的观点当成研究发现报告。始终分清"作者认为……"与"材料表明……"。
  3. 识别主要趋势或模式。 结果彼此不一致时，可以基于大多数文章概括，或只基于证据最强的文章概括——但必须向读者说明你概括的基础。
  4. 找出空白点并说明成因。 空白常真实存在（某些方向研究难度极大），记录它、解释它，并在规划综述时纳入考虑。
  5. 识别各项研究之间的关系 ⭐。里程碑研究提供了新方法，后续研究在此基础上探索；两篇文章探讨同一问题但材料/时段不同。写作时把相关文章放在一起讨论。
  6. 注意相关程度。 与主题无关的研究不该放进综述；笔记中要指出该研究与主题相关的具体方面。只有在确认没有直接相关文献时才引用外围研究，且要谨慎并说明。

另外三条随手可做：

  • 开篇用具体数据，不用泛泛陈述（"超过 10% 的男女报告……" 远胜 "许多人是受害者"）。
  • 留意综述文章并概括它们——这是最高效的领域地图。
  • 长引语几乎总是不适当的；只记简短但重要的引语（精准定义、关键法律/制度条文），并当场记下页码。
  • 记方法价值与缺陷：不要逐篇罗列每个缺陷，记主要缺陷，留意各组研究的缺陷模式并成组讨论。

计量与数字人文研究怎么评#

涉及计量研究、数字人文、接受史调查时，用下面几条（版本考订与文本阐释不适用，回到领域准则）：

  1. 数据来源是否交代清楚——库名、所据版本、OCR 识别错误率是否说明、抽样范围与时间跨度。
  2. 样本是否覆盖关键材料——只抽取某一种刻本、某一类选本、某一个数据库，结论的外延就受限制，要指出。
  3. 统计口径是否可比——不同研究对同一变量的统计方式常常不同；若用不同方法的研究得出相似结果，这是对结果的强支持；结果差异也可能源于口径差异，而非事实差异。
  4. 结果是否回到文本验证 ⭐——词频、共现、社会网络的结果必须回到具体文本检验，否则只是数据现象。
  5. 看差异的实际大小，而不只是统计显著性。
  6. 假设所有计量研究都有缺陷——永远不用"证明"，记录主要缺陷，并尽可能成组评判。

若题目涉及访谈、田野等质性方法，其评价标准（取样方式、是否成员检查、分析步骤是否可复现等）属通用质性研究方法范畴，此处不展开，需要时查阅该领域方法教材。

用表格整理笔记#

表格是给读者用的，不是给自己用的。早期可以建很多表来掌握全貌，成稿只保留必要的：

  1. 定义表 —— 两种情形特别需要：某概念有大量密切相关的定义（便于横向比对）；某概念的定义随历史演变（按时间顺序排列，可看出趋势）。
  2. 方法/材料表 —— 因为方法与材料差异会导致结论差异。可增加一行说明其证据类型（刻本对校、出土文献、数据库统计等）。
  3. 在表中纳入结果摘要 —— 结果摘要优先用叙述方式；只有各研究统计口径可比时才给数字。
  4. 文献多时明确准入标准 ⭐ —— 若只摘要部分研究，必须写明标准："表 1 仅包括经过多版本对校的整理本""表 2 总结近十年的研究成果，因为该问题的看法随时间变化"。

使用规则：只为复杂材料提供表格（综述不应该是表格的集合）；每张表必须在正文中介绍并讨论（不必逐项复述）；配表号 + 说明性标题；跨页时表底标"（续）"，下页重复表号 + "（续）"。

评价一部研究时的十个问题#

读每一篇研究，用这十个问题做笔记，比"摘要 + 方法 + 结论"更有用：

  1. 它问的是什么问题？ 这个问题是真问题，还是作者自设的伪问题？
  2. 它用什么材料？ 原典、版本、目录、出土文献、域外汉籍，还是二手研究？
  3. 它的版本依据是什么？ 底本、参校本、整理者、页/叶是否交代？
  4. 它的论证链是什么？ 哪一步是关键的？有没有跳步？
  5. 它的核心证据是什么？ 是孤证、旁证，还是多重证据？
  6. 它如何处理反证？ 主动回应、轻描淡写，还是完全忽略？
  7. 它和谁对话？ 继承、修正、反驳了哪一说？
  8. 它的方法适配吗？ 理论是否服务于问题，还是问题被理论牵着走？
  9. 它的结论有多大效力？ 能解释多少文本？有没有过度概括？
  10. 它留下了什么问题？ 材料、版本、方法、概念上还有什么未决？

证据摘录卡（建议格式）#

【文献】作者《篇名》，《刊名》年份期数。
【问题】
【材料/版本】
【核心论点】
【关键证据】原文 + 卷次/页叶（已核/待核）
【反证/异说】
【我的判断】强/中/弱；理由：
【可放入大纲】Ⅲ-2 / Ⅳ-1

处理转引#

  • 能回查原书，就回查；笔记中写"已核原书"。
  • 不能回查，写"转引自某某"，并在正文注释中如实标注。
  • 不要为了显得材料丰富，把转引伪装成直接引用。

处理海外研究#

  • 先看它的问题意识与材料条件，再看结论。
  • 关键概念核对原文；中译本可能有删节、误译、术语替换。
  • 不要因为作者是海外学者就默认"新颖"，也不要因为理论来自西方就默认"不适用"。
  • 评价标准仍然是：材料是否可靠、论证是否成立、能否解释文本。

阶段三 · 综合与初稿

阶段三：综合与初稿

目标产出：主题大纲 → 初稿。 结构范式、学术史写法、争议处理、结论与未来研究的写法，一律以 domain-ancient-literature.md 为准；本册只讲综合与落笔的动作。 落笔前先读 model-passage.md 的示范段落，按它的句式与脚注体例写。

一、综合：从笔记到论点#

到这里，最困难的部分（分析、综合、规划论证）其实已经完成。剩下的只是把智力劳动转化为叙述。

先定目的和文风#

学术文风要求作者不突出自己，把注意力集中在内容上。

不当："笔者认为贾谊的赋作非常重要，笔者将展示其独特的艺术价值。" 得当："贾谊赋在汉赋由骚体向散体大赋过渡中的位置，近年因《鵩鸟赋》作年考订的推进而重新成为问题。"

学术写作通常慎用第一人称——让材料和论证说话，而不是"我"。

重组笔记，而不是重排笔记 ⭐#

仅仅给出一系列研究注释几乎总是不可接受的。 那是描述一棵棵树，而你应该描述森林——并且是一座你自己造出来的新森林。

做法：建主题大纲勾勒论点 → 在笔记表新增一列填入对应大纲编号 → 回到大纲，在各标题旁标注具体参考文献 → 用分析细节充实大纲（优势与劣势、空白点、研究间关系、主要趋势）。充实后的大纲应有好几页长。

同一条文献可以在多处出现——只要它与该处论点相关；不要在综述某处总结一篇后就把它从后续讨论中剔除。

综合时要做的四件事#

  1. 在每个标题下注明不同研究的差异，并对结果的不一致做出评论与解释（是否因为部分研究更老旧？是否所用材料不同——刻本系统与出土文书？）。
  2. 在每个标题中寻找空白点，并说明它为什么存在。
  3. 简要说明相关理论：先总结初始理论 → 再总结支持它的研究 → 最后指出其尚未被检验的边界。若领域内有相互矛盾的理论，讨论所综述的文献在多大程度上支持各自。
  4. 定期总结：长篇复杂主题需要分阶段总结，末尾再总括一次，为结论铺路。

二、落笔的要点#

  1. 从宽泛的问题领域开始，但避免空泛。 经验法则是"从一般到特殊"，但"一般"有下限。

空泛："近年来，赋体研究越来越受到学界关注，成果丰硕。" 到位："1980 年以来，贾谊赋研究论文约 96 篇、专著 19 部；其中作年考证、本体阐释与渊源影响三块最为集中。"

  1. 开头就说明主题为什么重要，并指出为什么某些研究是重要的（新材料？新版本？改变了问题？）。

  2. 区分研究发现和其他信息来源 ⭐。用引导词标明性质：观点或推测用"推测……""有人建议……"；研究发现用"在……的调查中发现……""材料表明……"。

  3. 叙述发展历程时时间框架要具体 ⭐。避免"近年来……越来越大"，要给出具体年份与百分比；若引用经典或里程碑研究，说明理由（开创问题、引领传统、关键术语的原始来源）；若里程碑研究被重复过，要提及并说明重复的结果。

  4. 结果不一致时分别引用，并推测原因 ⭐。

不可取："各家对作年的判断差异很大，从文帝六年到九年不等。" 可取："以《汉书·文帝纪》天气记载为据者断为文帝九年，以马王堆三号墓出土文书与传世史料互证者断为文帝七年。分歧不在解释，而在证据层级。"

  1. 避免冗长、泛泛的参考文献列表 ⭐。

不可取：句末堆一串十七个作者。 可取："许多学者认为贾赋承楚辞传统（e.g., see 龚克昌，1985；曹道衡，1989）。最近的两项研究提供了更可靠的证据（张强，2006；王学军，2018）。其中王学军（2018）以出土文书与传世史料互证，证据最为充分。"

用 e.g., see（例如，见……）表示只列举了部分可能引用；用 cf.（比较）表示可对照。

  1. 说明边界与空白的理由。 省略某个相关问题必须给出理由；宣称空白必须交代检索策略（哪些库、检索日期、关键词），最好在开头就说明。同时讨论关于该主题的其他综述，并说明本文与它们的差别（更新？更全面？结论不同？）。

三、让文章连贯#

  1. 长篇开头提供概述，明确说明涵盖与不涵盖什么，并开篇明确你的观点——用简明的一段告诉读者，是哪一个总体观点在指导你对文献的解释与综合。（注意：这条说的是什么时候表达观点，不是什么时候形成——观点应在通读并思考全部文献之后才形成。）

  2. 追求清晰连贯，避免注释化表述 ⭐⭐。注释化表述 = 对文章内容的简要概括。把若干注释化表述串起来，只能说明这个主题有哪些研究，不能为读者组织材料。 组织形式应当是专题性的，而不是围绕个别作者。一段里引用多项研究，但围绕的是同一个论点。

  3. 用子标题与过渡词帮读者追踪论点（尤其长篇）。子标题的位置要能推进论点。过渡用"第一/第二/最后"，但不要过度使用元评论（"本文下一部分将介绍……接下来是……"）——偶尔可以，频繁重复已说过的话就是问题。 跨学科主题可分学科综述。

  4. 结尾写出结论并检查连贯性。 独立综述的结论要明确说明材料如何支撑导言中的主张；学位/期刊论文的综述则引出研究问题。长篇复杂综述先简要总结论证主线，再给结论。 检查：各部分联系有多紧密？子标题、过渡词与修辞标记（"下一个例子""相关研究""一个反例""最新研究"）都是读者的导航工具。

古代文学领域增强

本节只保留"写作动作层面"的内容。 结构范式、学术史写法、争议处理、结论与未来研究的写法，已统一归入 domain-ancient-literature.md 第五、六、九节，以那份为准。下面四项是 domain 文件未覆盖的落笔细节。

一、把"版本/史料"写进论证，而不是塞进脚注#

古代文学的许多分歧，实质是底本不同、篇目不同、系年不同、作者归属不同。综述必须把这一层显性化：

  • 先交代文本基础：本文所据何本？为何用此本？重要异文是否影响结论？
  • 遇到结论分歧，先查是不是材料分歧：两家结论相反，是解释不同，还是所据版本/系年不同？
  • 版本谱系要能说清承属：稿本 → 抄本 → 刻本 → 翻刻 → 点校整理本，哪一环节产生了关键异文。
  • 不要用晚出的整理本冒充古本：引用整理本要注明整理者、出版社、版次；引用影印本要注明所影底本。
  • 区别"文献事实"与"文学阐释"：作者归属、系年、文字异同属可考证的事实层；风格、意旨、影响属阐释层。两层可以互相支持，但不能互相替代。

二、句子以问题为主语#

注释化表述的根源是句子主语永远是"某某"。改写方法：让问题、文本、分歧、方法做主语。

弱 强
张三（2010）研究了李白诗歌的用韵。李四（2015）也研究了这个问题。 李白用韵的分歧，集中在是否受方言影响。张三（2010）以……为据主张……；李四（2015）则指出……
王五认为《长恨歌》的主题是爱情。赵六认为是讽喻。 《长恨歌》主题之争，实质是对"讽喻"证据的认定不同：王五强调……，赵六则把……读作……
近年来，数字人文受到关注。 2010 年代以来，CBDB、CHGIS 等数据库使……成为可能，但……

每段第一句必须是本段的论点，不是"某某研究了……"。写完一段后遮住其余句子，只看首句，若能读出这一段在论证什么，才算合格。

三、直接引文的纪律#

  • 古代文学综述引用原典，必须核对底本，不能从二手研究转引而不说明。
  • 诗、词、曲引文保持原有断句与异体字；如有改动，用校勘符号或注说明。
  • 引文超过三行另起 block quote；但能用一句原文说清的，不要引整段。
  • 引用现代研究者的观点，优先转述；只有定义、关键判断、争议性表述值得直引。
  • 每条引文都要问：它是在提供证据，还是在提供权威？后者通常可以转述。
  • 引文不能代替论述：遮住所有引号内的内容，剩下的文字仍须读得通、仍有论点（见 editions-and-citations.md 第五节第 8 条）。

四、初稿自检（写完一节就做）#

  • [ ] 这一节的论点能用一句话说出来吗？
  • [ ] 段落首句是论点，而不是作者名？
  • [ ] 有没有连续三段都是"某某 + 观点"的结构？
  • [ ] 版本、系年、作者归属的交代，是否出现在需要它的论证位置？
  • [ ] 争议是否写出了"争什么、凭什么、谁更强"？
  • [ ] 有没有把"作者的论断"写成"研究的结论"？
  • [ ] 有没有出现"证明""毫无疑问""众所周知"？
  • [ ] 每一条引文都能回到原书原卷原页吗？
  • [ ] 这一节与上一节的衔接句，是否说明了推进关系（而非"接下来"）？

中文期刊综述的体裁要件

本节内容已按领域规则并入 domain-ancient-literature.md（摘要/关键词/引言要件 → 第九节；正文展开手法 → 第五节「两层不要混」）与 editions-and-citations.md（图像与图表的许可与来源、引文不能代替论述 → 第五节第 7、8 条）。请以那两份文件为准。

通用写作教材（如陈立宏等《关于研究生文献综述撰写的几点建议》，《教育教学论坛》2022 年第 31 期，149–152）给出的条目，是理工科与社科口径的体裁规范。它们在古代文学领域的适用情况如下：

条目 在古代文学领域
摘要 200–300 字、关键词 3–5 个 适用，但摘要须能回答"综述的是哪个问题、覆盖哪些材料与时段、判断是什么"

阶段四 · 编辑与终稿

阶段四：编辑与终稿

关键角色转换：此前你是分析、评价别人作品的人；现在你的初稿是被分析评价的对象。 第一步：把稿子放一边几天，与它拉开距离。第二步：从"想让读者读懂我的论点"的角度重读。 体例细节一律以 editions-and-citations.md 为准；本册讲通用的修改动作。

一、编辑与采纳反馈#

读者永远是对的 ⭐#

这是修改过程中最重要的一条。受过教育的读者不理解你的某个观点，沟通就不成立。为初稿辩解通常适得其反——去找出读者为什么不懂：分析有误？背景不足？缺过渡？

取反馈的顺序#

  1. 尽早获取对内容的评论。若初稿满是格式错误（拼写、标题错位），导师会先把精力放在这些上而推迟内容评论——先让稿子可读。
  2. 先集中精力评论想法，格式问题后面处理。
  3. 通过澄清调和矛盾的反馈。评阅人意见相左（一位要你加细节、一位要你删）是常态。你的责任是：① 确认分歧不是因为有人没看懂你的论点；② 与双方讨论达成妥协。
  4. 格式意见与体例手册对齐（MLA / Chicago / GB/T 7714 等）。一旦确定，就要一丝不苟地遵守。
  5. 为反馈和修改留足时间 ⭐。至少做一次较大修订，专业作者定稿前常有三稿以上。

对照大纲与结构#

  • 把初稿与主题大纲对照：大纲定义了论证路径，检查初稿是否确实遵循了它。
  • 检查结构的平行性 ⭐：读者期待平衡——讨论了缺点就要有优点；支持某立场的论点要有反对论点来平衡。若确实没有反方研究，要明确说明这一点（空白点要有检索依据）。

引语与术语#

  • 避免过度使用直接引语，尤其长引语 ⭐。断章取义的引语传达不了作者原意；解释引语全部内容又会引入无关细节。转述通常更有效，且能避免不同作者文风打架造成的混乱（转述仍需引用）。很少有人能接受以引语开始一篇综述——在建立语境之前，读者体会不到引语的预期效果。
  • 避免对反复出现的词语使用同义词 ⭐。学术综述不是创意写作，必须坚持使用常规术语，即使重复。 混乱示例："凤凰组……另一组青少年……第 1 组……实验组"（同一组四个叫法）；清晰写法："实验组……对照组"（一贯使用）。

一般写作习惯#

  1. 句子完整——大声朗读，卡住的地方就是要改的句子。
  2. 慎用第一人称（可用，但不过度）。
  3. 避免性别化语言（用复数，或交替使用，或"他或她"）。
  4. 避免间接结构与被动语态（"在某某的研究中……被发现" → "某某发现了……"）。
  5. 数字规则：0–9 拼写，10 及以上用数字（图表编号、小数与公制单位除外）；名词后跟数字表序列时名词大写（Item 6、第 12 卷）；句首是数字时拼写完整，或改写句式让数字不在句首。

标题与读者友好#

  • 标题要简明且说明性：明确研究领域并告诉读者你的观点。避免"可爱"的标题（双关、典故会分散注意力），经验法则约 10 个字。
  • 读者友好清单：拼写检查 + 人工校对（拼写检查抓不出同音错别字）；所有页面编号（否则评阅人无法引用具体位置）；行距与页边距按刊物要求；装订可摊平；含标题页；至少保留一份备份；纸质提交要打印清晰；避免花哨修饰（彩色高亮改用斜体、混用字号、剪贴画）。

引用与学术诚信 ⭐⭐#

所有非自己的文字和想法都必须引用。 作者—日期法要点：

  • 叙述式：陈寅恪（1950）；括号内多个引用用分号分隔：(Black, 2014; Brown, 2015)。
  • 直接引用必带页码；转述通常只需作者 + 年份。
  • 二手来源标注为"转引自"——只有你实际查阅的那一条进参考文献列表。

避免剽窃。 常见情形：

  1. 未经引用使用他人的文字。
  2. 未经引用使用他人的观点（换词或调序仍算）。
  3. 引用了但复制原话不加引号（有出处也照样算剽窃）。
  4. 借用他人的短语或句子结构而不注明。
  5. 借用他人论文的全部或部分，或用他人的大纲。
  6. 使用代写服务。

古代文学最常见的翻车点：从二手研究里转引原文而不回查原书。看到 A 引用了《史记》某句，就直接把这句抄进自己的综述并标注《史记》——这是把转引伪装成直接引用。凡未核对原书的，一律写"转引自 A"，并尽可能回查原书。

需要时就寻求帮助：写作课、工作坊、写作中心、校对人员。别指望导师替你编辑格式和行文。

二、参考文献列表#

通用原则（具体格式见 editions-and-citations.md 与目标刊物规范）：

  1. 只包含在正文中实际引用过的文献——没被引用的不要列。
  2. 排列有序（作者姓氏字母序，或 GB/T 7714 的顺序编码制），全篇统一。
  3. 格式细节要特别注意：大小写、标点符号、卷号与期号、页码标识（部分体例不用"p./pp."）。
  4. 不要画蛇添足（如多余的页码缩略语）。
  5. 在线资源提供访问日期与完整网址；无日期用"n.d."；无作者用机构名。
  6. 逐条对照正文 ⭐：正文每条引用都在列表里？列表每条都在正文被引用？作者姓名拼写与出版年份在各处是否一致？

用文献管理软件（Zotero / EndNote 等）可以省下大量排版工夫，但生成的条目必须逐条交叉检查——自动导出的引文常多出期号、缺出版地或大小写不符。

古代文学领域增强

一、改稿轮次（领域版）#

古代文学综述的修订顺序应调整，文献层必须早于语言层：

  1. 轮 1 — 文本与材料：底本是否交代？引文是否核对原书？版本、卷次、页码/叶码是否准确？作者归属与系年是否有据？
  2. 轮 2 — 论证与结构：是否以问题为经？每一节是否有论点？争议是否写出证据强弱？是否存在"作者+观点"串烧？
  3. 轮 3 — 覆盖与学术史：大陆、港台、海外是否都有交代？里程碑研究是否缺席？近 10–20 年成果是否覆盖？旧文献是否给了理由？
  4. 轮 4 — 注释与著录：体例是否统一？脚注与文末参考文献是否双向匹配？每条转引是否标明？
  5. 轮 5 — 语言与格式：术语、繁体/简体、标点、数字、标题、篇幅。
  6. 轮 6 — 逐项过领域检查表。

二、注释体例的三条硬规则#

  1. 一篇论文只用一种体例。要么全用脚注（《文学遗产》《历史研究》式），要么全文末参考文献 + 文中括注（GB/T 7714 式）。不要混用。
  2. 古籍引证必须能定位到卷、篇、页/叶。只写书名和出版社，等于没引。
  3. 转引必须标明。写"转引自某某书，第 X 页"，并尽可能核对原始出处；不能把转引伪装成直接引用。

常用脚注格式（《文学遗产》式，细节以目标刊物最新规范为准）#

司马迁：《史记》卷四七《孔子世家》，北京：中华书局，1959年，第6册，第1921页。
（汉）班固：《汉书》卷三〇《艺文志》，北京：中华书局，1962年，第6册，第1701页。
（宋）苏轼：《苏轼文集》卷一《赤壁赋》，孔凡礼点校，北京：中华书局，1986年，第1册，第5页。
（清）姚际恒：《古今伪书考》卷3，光绪三年苏州文学山房活字本，第9页a。
（清）杨钟羲：《雪桥诗话续集》卷5，沈阳：辽沈书社，1991年影印本，上册，第461页下栏。
乾隆《嘉定县志》卷12《风俗》，第7页b。
《清德宗实录》卷435，光绪二十四年十二月上，北京：中华书局，1987年影印本，第6册，第727页。

要点：

  • 朝代括注用于常见古籍，视刊物要求取舍；同一篇内统一。
  • 卷次：传统古籍多用汉字（卷四七），民国以后整理本与期刊常可用阿拉伯数字，但全文统一。
  • 册次在出版社之后、页码之前。
  • 叶码用 页 a / 页 b / 页 a—b；影印本可标"上栏/下栏"。
  • 出版社写全称，前加出版地；港澳台与国外出版地照录。
  • 整理本注明整理者（点校、笺注、校注）。
  • 再次引证可省出版信息，但仍需卷次、册次、页码。

GB/T 7714—2025 提示#

现行国家标准为 GB/T 7714—2025（2025-12-02 发布，2026-07-01 实施，替代 GB/T 7714—2015）。与旧版相关的关键变化包括：责任者著录规则、图书与地图的格式、网站/网页的著录、[PP] 等文献类型标识、作者姓名大小写、仅在线资源需标注引用日期、PID 的著录。投稿前以目标期刊的最新征稿规范为准；标准原文与实施信息见国家标准全文公开系统 https://std.samr.gov.cn/。

三、逐条核对引文（必须动手，不能凭印象）#

对每一条引文，建立一行记录：

检查项 做法
书名/篇名 与版权页、目录页逐字对照，注意异体字与简称
作者/编者/整理者 与版权页一致；古籍原题与通行署名不同时说明
版本 初版/再版/修订版/影印本/点校本，不能只写出版社
卷次/篇名 核对是否为目标文字所在卷
册次 多册本必查，避免"第 3 册"写成"第 3 卷"
页码/叶码 核对单页/双页、a/b 面、上/中/下栏
引文文字 与底本逐字比对；异体字、通假字是否保留
标点断句 古籍引文是否沿用底本断句；改动是否说明
转引 是否标明"转引自"，是否核对原书
二次引用 正文与文末条目是否一致

页码错误是古代文学论文最常见、也最致命的硬伤。 评阅人只要随手翻一页对不上，整篇的可信度就会崩塌。

四、术语与文字的一致性#

  • 人名：同一人用同一称法。苏轼/苏东坡/苏子瞻，正文择一，首次出现可括注字号；不要一段一换。
  • 书名：全称与简称统一。首次出现用全称（含卷数），后文可用简称，但要在前言或首次出现处说明。
  • 版本名：宋刻本、元刻本、明嘉靖本、清乾隆武英殿本——朝代 + 刊刻者/年号 + 本，格式统一。
  • 文体名：赋、骈文、古文、时文、传奇、话本、章回小说——不要用现代概念强行替代。
  • 繁简：大陆刊物通常简体，但引文中的异体字、通假字、避讳字如需保留，应说明；港台刊物可能要求繁体，投稿前确认。
  • 数字：卷次、篇次按体例；年份、页码用阿拉伯数字；"一二三"用于列举或固定搭配。

五、标题与摘要（古代文学版）#

标题要包含：研究对象 + 问题/角度（+ 时段，如需要）。

  • 可取：《从"诗史"到"诗圣"：杜甫接受史上的一个转折》
  • 可取：《〈文心雕龙〉"通变"观的版本依据与理论内涵》
  • 不可取：《杜甫研究综述》（太泛，没有论点）
  • 不可取：《一场美丽的误会——论……》（"可爱"标题，分散注意力）

摘要（如需要）四句：问题 → 范围与材料 → 主要判断 → 意义。不要写"本文分为三部分"。

六、终稿前的"三遍读法"#

  1. 逆读：从结论倒着读每一节，检查每一节是否真的在支撑上一节。
  2. 抽读：只看每段首句，能否连成一条完整论证链。
  3. 查读：随机抽 10 条引文，逐条回原书核对；错 1 条，全篇重查。

七、领域终稿红线#

  • [ ] 没有交代底本/版本就展开阐释。
  • [ ] 引文从二手研究转引，却未标明。
  • [ ] 卷次、册次、页码/叶码有一处对不上。
  • [ ] 全文脚注与文末参考文献体例混用。
  • [ ] 只综述大陆研究，港台/海外完全缺席（除非题目明确限定）。
  • [ ] 里程碑研究缺席，或列了却没说明为什么重要。
  • [ ] 通篇"某某认为"，没有作者自己的判断。
  • [ ] 用"证明"描述考证结论。
  • [ ] 结论只说"未来需要更多研究"。
  • [ ] 正文引用与文末条目不能双向对应。
