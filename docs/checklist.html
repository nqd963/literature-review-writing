中国古代文学综述：领域自我编辑检查表（60 项）

用法：初稿完成后先过"硬伤 10 条"，再逐项过 60 条。每一条都要能拿出证据，不能凭感觉打勾。 与通用检查表的关系：本表优先；checklist-self-edit.md 的 90 项用于补充语言、格式、程序性检查。

零、硬伤 10 条（先过这一遍）

  • [ ] 1. 引用古籍只写书名，不写版本、卷次、页/叶？
  • [ ] 2. 从二手研究转引原文，没有回查原书？
  • [ ] 3. 用电子检索/OCR 文本直接充当引文，没有核对影像或整理本？
  • [ ] 4. 只引大陆研究，港台/日本/欧美的重要成果缺席？
  • [ ] 5. 只引近五年，奠基性成果与经典考证没有进入学术史？
  • [ ] 6. 先有观点再挑材料，反证被忽略或轻描淡写？
  • [ ] 7. 用当代概念/西方理论直接套古代文本，不说明适用条件？
  • [ ] 8. 写成"某某认为……某某又认为……"的流水账？
  • [ ] 9. 宣称"研究空白"却不交代数据库、关键词、日期、语言？
  • [ ] 10. 用"证明"代替"表明/支持/提示"？

任何一条为"是"，先改，不要进入下面的细项。

一、选题与范围（1–8）

  • [ ] 1. 研究对象能用一句话说清：作家、作品、文体、主题、意象、流派，还是文献问题？
  • [ ] 2. 时段明确（朝代/年份），没有"古代""历代"这类过宽表述？
  • [ ] 3. 文体明确（诗/词/文/赋/小说/戏曲/文论），没有把不同文体混为一谈？
  • [ ] 3b. 三条边界都写明了吗（时间 / 对象 / 体裁）？题目是否"小到可穷尽文献、大到有足够成果可评"？
  • [ ] 3c. 若对象在古代评点丰富，古代部分是否单列，形成了"古代评点史 → 现当代研究"两段式？
  • [ ] 4. 文本/版本范围明确：哪些作品纳入、哪些不纳入、为什么？
  • [ ] 5. 核心问题是一个可回答的学术问题，不是"研究 X"或"论 X 的特色"？
  • [ ] 6. 本文论点可以被反驳，不是"X 很重要""X 很有价值"？
  • [ ] 7. 导言说明了涵盖与不涵盖的范围，且理由充分？
  • [ ] 8. 题目规模与篇幅匹配，能在规定字数内完成？

二、检索与覆盖（9–18）

  • [ ] 9. 覆盖了与题目相关的大陆、港台、日本、欧美研究传统？
  • [ ] 10. 视题目需要，使用了中文、英文、日文中的至少两种语言？
  • [ ] 11. 原典/古籍与研究文献分开检索，没有用一个库包打天下？
  • [ ] 12. 至少使用了三类库：研究文献库 + 古籍影像/全文库 + 书目/工具库？
  • [ ] 13. 检索日志完整：日期、库名、检索式、限定条件、命中数、纳入/排除理由？
  • [ ] 14. 对核心文献做了反向追踪（读其参考文献）？
  • [ ] 15. 对核心文献做了正向追踪（查其引证文献）？
  • [ ] 16. 查阅了近 3–5 年的年度综述、研究年鉴、书评或会议综述？
  • [ ] 17. 查阅了相关学位论文，并对其关键判断追溯原始研究？
  • [ ] 18. 宣称"空白"前，交代了检索范围、数据库、关键词、日期与语言限制？
  • [ ] 18b. 统计口径交代了吗（时间范围 + "论文约 X 篇，专著 Y 部"）？数字可核查吗？
  • [ ] 18c. 用过《古典文学研究资料汇编》一类资料汇编吗？（写古代评点部分的独门武器）
  • [ ] 18d. 选本是否被当作研究对象（而不只是别人的整理成果）？

三、文献与版本（19–30）

  • [ ] 19. 底本明确：版本类型、整理者、出版社、出版年、版次？
  • [ ] 20. 参校本明确：参校了哪些版本，各属什么系统？
  • [ ] 21. 关键引文核对过影像、原书或权威整理本？
  • [ ] 22. 区分了古人原文与整理者的标点、校记、笺注、按语？
  • [ ] 23. 关键异文有交代：从某本、两存、存疑，而不是 silent 改字？
  • [ ] 24. 作者归属/真伪有交代：采信哪一方、依据是什么、是否存疑？
  • [ ] 25. 系年有依据：采用哪家年谱/编年，异说如何处理？
  • [ ] 26. 辑佚注明出处、原文、异文与真伪判断？
  • [ ] 27. 出土文献/域外汉籍注明定名、缀合、释读、藏地与版本依据？
  • [ ] 28. 没有用电子 OCR 文本直接引用；如用，已核对影像？
  • [ ] 29. 没有把伪书、误题作者、后人增补的文字当作可靠史料？
  • [ ] 30. 对书目/目录/工具书的收录范围、成书年代与著录错误有警觉？

四、学术史与问题意识（31–40）

  • [ ] 31. 有明确的学术史分期或问题脉络，不是"人名 + 书名 + 年份"的堆叠？
  • [ ] 32. 每一期都说明了：核心问题、代表成果、材料/方法、贡献、局限？
  • [ ] 33. 里程碑/经典研究已收录，并说明了它为什么是里程碑？
  • [ ] 34. 说明了经典研究与后续研究的关系：继承、修正、推翻，还是重复验证？
  • [ ] 35. 梳理出 3–5 个核心争议，并说明各方的证据与方法差异？
  • [ ] 36. 区分了"作者的论断"与"研究提供的证据"？
  • [ ] 37. 海外汉学不是装饰：说明了其问题意识、材料条件与理论框架？
  • [ ] 38. 没有用西方理论直接套中国古代文本；如用，说明了概念来源与适用边界？
  • [ ] 39. 说明了自己的研究位置：继承什么、修正什么、补充什么？
  • [ ] 40. 对"最新研究"有质量判断，没有把"新"等同于"重要"？

五、论证与结构（41–50）

  • [ ] 41. 有贯穿全文的论点，不是各节互不相干的资料汇编？
  • [ ] 42. 结构是问题导向/论证导向，不是作者导向或成果导向？
  • [ ] 43. 每一节都能对应大纲中的论证任务，没有跑题？
  • [ ] 44. 每一段有主题句，段与段之间有因果、对比、递进或细化关系？
  • [ ] 45. "述"与"评"结合，不是只述不评，也不是只评不述？
  • [ ] 46. 评价有具体证据，不是"很有价值""非常重要""研究不足"？
  • [ ] 47. 处理了反证与异说，没有选择性使用材料？
  • [ ] 48. 没有用"证明"；用"表明""支持""提示""似乎可以得出"？
  • [ ] 49. 结论回应了导言提出的问题与论点？
  • [ ] 50. 未来研究方向具体：新材料、新版本、新群体、新方法、新问题？
  • [ ] 50b. 分类是否超过三级？（三级封顶，再细就是流水账）
  • [ ] 50c. 考证是否单列一节（系年/版本/辑佚/辨伪/生平交游）？
  • [ ] 50d. 学术史的转折是否点出了外部成因（思潮、制度、新材料发现），而不只是描述转移本身？
  • [ ] 50e. 批评是否具体到人和篇？有没有"研究不够深入"这类空话？
  • [ ] 50f. 结语的"未来方向"是不是就是我自己的选题？如果不是，说明选题还没找到。

六、引文与注释（51–60）

  • [ ] 51. 注释体例统一：目标刊物/学校要求的是脚注、尾注还是参考文献制？
  • [ ] 52. 首次引证要素齐全：作者、书名、卷次、篇名、版本、册次、页/叶？
  • [ ] 53. 再次引证简写规范，且同一篇文章内前后一致？
  • [ ] 54. 卷次数字形式统一（《文学遗产》简式汉字/部分刊物阿拉伯数字），没有混用？
  • [ ] 55. 页码/叶码准确：多册书注册次；影印本用页 a/b 或上/中/下栏？
  • [ ] 56. 出版社用全称；台港澳/外国出版地、出版者按体例处理？
  • [ ] 57. 期刊论文、学位论文、网络资源、数据库的格式正确？
  • [ ] 58. 正文引用与文后参考文献双向匹配，没有"有引无目"或"有目无引"？
  • [ ] 59. 作者姓名、出版年份、标题在各处拼写一致？
  • [ ] 60. 所有转引都已回查原书；无法回查的，明确标注"转引自"？

七、加分项（不是必须，但能显著提升质量）

  • [ ] 附检索日志，读者可复现你的"研究空白"判断。
  • [ ] 附版本谱系表，读者能一眼看出底本/参校本关系。
  • [ ] 附争议表，读者能快速把握各方证据与方法差异。
  • [ ] 附引文核对表，编辑抽查时能迅速定位。
  • [ ] 对海外研究的关键概念附原文，避免翻译失真。
  • [ ] 对不可见材料/无法核对版本明确说明限制，不装作全知。

八、最后三问

  1. 如果导师只读你的综述，他能说出这个领域的三条主要脉络、两个核心争议、一个真正空白吗？
  2. 如果编辑抽查三条引文，你能在五分钟内拿出影像或原书吗？
  3. 如果五年后有人重做这个题目，你的综述还能作为一张有用的地图吗？

三问都能答"能"，才算真正完成。
