范文解剖：两篇真实的古代文学研究综述

抽象规则看十遍，不如拆一篇范文。本文件解剖两篇已发表的综述： ① 李建英《陆游诗研究综述》，《北京青年政治学院学报》2009 年第 3 期 —— 通代 / 长时段范例 ② 李怡蕾《近四十年来贾谊赋研究综述》，《宁夏师范学院学报》2020 年第 8 期 —— 断代 / 专题范例

配合 domain-ancient-literature.md 使用：那里讲规则，这里讲规则在真实文章里长什么样。

一、两篇范文的对照#

陆游篇（通代长时段） 贾谊篇（断代专题）
时间范围 南宋 → 当代（约 800 年） 1980–2019（40 年）
对象体量 存诗近万首，论文约 370 篇 赋 5 篇，论文约 96 篇、专著 19 部
主轴 时间（南宋 → 元 → 明清 → 现当代） 研究问题（考证 / 本体 / 继承与影响）
二级分类 现当代部分按成果形态（传记 / 年谱 / 选本 / 文学研究 / 学位论文 / 论文） 按切入角度（意象 / 创作风貌；继承 / 影响）
处理海量文献 表格清单 + 关键著作重点评述（4 张表） 三级分类 + 同观点者以"此类研究还包括……"带过
最大特色 古代评点单列为第一部分 结语点名批评四类毛病

关键判断：对象的体量决定综述的写法。 陆游存诗近万首、论文 370 篇，逐篇评述必然失控，所以用"成果形态分类 + 数量统计 + 表格"；贾谊赋只有 5 篇、论文 96 篇，可以做到逐层深入、逐篇点名。

二、陆游篇：通代综述的两段式结构 ⭐#

这是本文件最重要的一条结构经验。

陆游篇的目录是：

一、从南宋到清代            ← 古代评点史，单列
  (一) 南宋时期
      1. 关于陆游的地位
      2. 关于陆游对前代诗人的继承
      3. 关于陆游诗歌的特点
  (二) 元代
  (三) 明清时期
二、现当代                  ← 现代学术史
  (一) 专著及博士、硕士论文
      1. 传记类（表）
      2. 年谱（表）
      3. 选本及校注（表）
      4. 文学研究（表）
  (二) 论文
      1. 生平交游考证（约60篇）
      2. 思想研究（约30篇）
      3. 各类诗歌研究及综论（约170篇）
      4. 诗论文论研究（约25篇）
      5. 名篇赏析（约65篇）
      6. 其它（约20篇）

为什么古代部分必须单列？

古代评点（序跋、诗话、选本评语、年谱）不是"研究文献"，而是"前研究史"——它们本身是研究的对象，也是后人对陆游的理解史。把它们和今人的期刊论文混编，会造成两个后果：

  1. 材料层级错乱（清代人的一句评语和 2005 年一篇硕士论文不该平起平坐）；
  2. 掩盖"接受史"这一整条线索——选什么、不选什么，本身就是批评史。

操作规则：若对象在古代已有丰富评点（陆游、杜甫、苏轼、陶渊明皆属此类），把古代部分单列为第一部分，与"现当代研究"并列，形成"古代评点史 → 现代学术史"两段式。陆游篇正是如此。

支撑古代部分的独门武器：孔凡礼、齐治平编《古典文学研究资料汇编·陆游资料汇编》。陆游篇几乎全部古代评语都来自这一本书——清代《陆游资料汇编》里收录了 158 家的评论。这类"资料汇编"系列是古代文学综述的独门武器，一本书往往能撑起半篇综述（详见 search-resources.md）。

数量处理：论文部分每个子类都给出数量（60 / 30 / 170 / 25 / 65 / 20 篇），总数"约 370 篇"。用"约"字，并说明时间范围（"从 20 世纪初到 2007 年"）。

结语角度（陆游篇的特色）：不是批评具体某篇，而是指出结构性失衡——"研究陆游的文学性专题著作仍然很少，只有有限的几部，这与陆游这个超一流大诗人的情形是不相符的"；"对陆游诗歌艺术的研究方面，也还显得浅显单薄，陆游诗歌本质性的特征还有待进一步提炼概括"。

三、贾谊篇：断代综述的三级分类 ⭐#

一、创作时间考证                    ← 第一级：研究问题（考证是独立板块）
二、作品本体研究（论文26篇，专著9部）
   (一) 意象研究                    ← 第二级：切入角度
       1. 单个意象（饶宗颐、刘畅）  ← 第三级：方法再分
       2. 综合意象（郑明璋、雷磊）
       3. 意象比较（杨江平、杨莉萍）
   (二) 创作风貌及特点研究
三、继承与影响研究（专著13部，论文32篇）
   (一) 继承研究：老庄 / 楚辞
   (二) 影响研究：对后世文学（14篇）/ 对文人
四、结语

三条规则：

  1. 考证是独立板块。 系年、版本、辑佚、辨伪、生平交游，是古代文学综述的固定栏目，贾谊篇第一节即"创作时间考证"。社科综述没有这个板块，通用方法论不会告诉你。
  2. 三级封顶。 三级以下不再细分——分类太碎，综述就变成流水账。
  3. 每一级开头给数量。 "论文共 26 篇，专著共 9 部""专著共计 13 部，论文共有 32 篇"。统计口径必须交代（"从 1980 年起至 2019 年的四十年来"）。

这段是标准样本（贾谊篇写王学军的一段）：

在王学军的文章发表以前，学界对《鵩鸟赋》所言的"单阏之岁"具体指哪段时间存在着争议，而这一问题关乎《鵩鸟赋》的创作时间……王学军认为前人的说法均有历法根据，差异出现的原因是史籍对汉武帝改历之后太初元年的纪年记载不统一，他根据长沙马王堆三号墓出土的文书和史料的佐证，推导出"单阏之岁"当指汉文帝七年……如此便解决了学界颇具争议的问题。

拆开看是六步：① 前人争议是什么 → ② 为何关键 → ③ 其方法/依据 → ④ 结论 → ⑤ 评价 →（隐含）⑥ 与前后研究的关系。

四、实操配方：分类为骨架 + 时序为血肉 + 对比为亮点 ⭐#

这是两篇范文共同的写法，也是本文件最可复制的一条：

  • 骨架（外层）：大框架按研究问题或成果形态分类（贾谊篇按问题，陆游篇现当代部分按形态）。
  • 血肉（内层）：每个板块内部按发表时间推进叙述（龚克昌 → 田宜弘 → 张强 → 王学军）。
  • 亮点（节点）：遇到观点分歧处停下来对比对举，分析各自依据与得失。

对应 domain-ancient-literature.md 第五节的"两层"框架：外层骨架用问题/争议式或对象式，内层手法用循序法（板块内部），分歧处切换对比法。一篇综述里内层手法是混用的，这没问题——只有外层划分标准必须全文统一。

每段的标准写法#

谁 + 在什么成果里 + 提出什么观点 + 依据是什么 + 与前后研究的承继／反驳关系 + 你的评价

六要素缺一不可。只写前三个就是注释化表述；缺"依据"读者无法判断；缺"关系"看不出学术史；缺"你的评价"就是文摘性综述。

对比法怎么写（贾谊篇的示范）#

争议一：贾谊是否继承屈原精神

立场 代表 依据
否 张永鑫（1985） 四点：怨愤非斗争精神；批判不切实际；"讯曰"误解屈原轻生；风格清峻哀凉与浪漫主义相去甚远
是 高光复、万光治、叶幼明 汉初骚体赋沿袭楚辞传统，能传达楚辞真精神
细化 孟修祥（2004） 《吊屈原赋》的怨怒精神、《惜誓》"出发—远游—回归"三段式结构直承屈原，兼承宋玉铺陈

争议二：如何评价《鵩鸟赋》中的消极思想

立场 代表 依据
完全批判 龚克昌 "没落阶级的思想情绪"；但承认具暂时性
不能全盘否定 高光复 从人格对照中可见积极取向
更包容 汪耀明（21 世纪） "有情可原"，翻转了此前激进批判

写法要诀：不是"A 说……B 说……"就完事，要写清分歧点究竟在哪一层——事实认定？价值立场？概念理解？材料依据？

争议二很有代表性：同一批材料，三代学者的价值立场变了（1980 年代阶级分析 → 1990 年代人格分析 → 21 世纪同情理解）。贾谊篇把这个变化写出来了，这就是"学术史判断"。

数量处理的三个技巧#

  1. 成果极多时：表格清单 + 关键著作重点评述（陆游篇 4 张表：传记 20 种、年谱 3 种、选本 31 种、文学研究 19 项）。
  2. 同一观点多家雷同：点出最早／最完备的一家，其余以"此类研究还包括……"带过。贾谊篇在列举老庄继承研究后加一句"此类论文还包括何易展《……》、佟田雨《……》、高树海《……》、李岩《……》、孙晓岚《……》和刘生良《……》等"，一口气带过六篇。
  3. 统计用"约"字，口径要说明（"从 20 世纪初到 2007 年，约 370 篇"）。

五、结语：三层结构，最后一层是你的选题 ⭐⭐#

两篇范文的结语都由三层构成，这是古代文学综述最有价值的部分。

第一层：已达成的共识#

贾谊篇： - 《旱云赋》《吊屈原赋》《鵩鸟赋》的创作时间已得到确认 - 贾谊辞赋具备汉大赋某些特征，并对后世文学产生了一定影响 - 继承并反映了老庄哲学，但这种继承具有暂时性；与楚辞也有密切关系

第二层：存在的不足（要具体到人和篇，不空谈）#

贾谊篇点名了四类毛病，可直接作为你写批评时的检查清单：

毛病 范文中的实例 检查自己的写法
重复研究，创新性不足 高胜利两文相隔三年，内容前后基本重合；李霁某节大段重复张强 你的综述是否只是重排别人的结论？
缺乏深层次分析 郭维森、许结《中国辞赋发展史》论《鵩鸟赋》承道家，仅单向罗列赋文，未结合道家著作分析 是否只述观点、不论证逻辑？
概念理解偏差 孙彦波等说继承"香草美人"传统，下文却写比喻对比手法，文不对题 概念是否用准了？
材料支撑不足轻下结论 曹道衡据《汉书·文帝纪》一条天气记载，直接断定《旱云赋》作年 孤证是否下了断语？

另可参照陆游篇的角度：成果形态失衡（传记、选本多，文学性专题著作少）、研究浅显单薄（本质性特征有待提炼）。

批评要指名道姓。 "研究还不够深入"是空话；"高胜利两文间隔三年而内容基本重合"才是学术批评。这不是刻薄——点名是为了让判断可核查。

第三层：未来方向 = 你自己的选题#

贾谊篇最后一段，从"贾谊辞赋对先秦文学的继承与创变"这一空白，自然收到**《鵩鸟赋》对《庄子》的文学性继承**——这恰好就是作者自己的研究生科研创新项目（见摘要与基金项目栏）。

这是综述最重要的功能：为你的学位论文圈定地盘。 结语写"尚有进一步研究空间"时，那个空间就应当是你论文的题目。写得越具体，你后面开题越省力。 反过来说也成立：如果你写不出具体的"未来方向"，说明你还没找到选题，回去重做第六步（列争议清单）。

六、可直接套用的提纲模板#

题目：近XX年 / 20世纪以来 【对象】研究综述

摘要 | 关键词

引言（或首段）
├─ 对象界定与文献底数（著录、存佚、真伪、版本）
├─ 时间范围与统计口径（论文 X 篇，专著 Y 部）
└─ 本文梳理框架说明

【若对象在古代评点丰富：第一部分单列"古代评点史"】
一、从【朝代】到【朝代】（古代评点史）
├─ (一) 【朝代】：地位 / 渊源 / 特点
├─ (二) 【朝代】
└─ (三) 【朝代】  ← 附该期重要选本

二、基础研究
├─ 生平、交游、仕履考证
├─ 作品系年、创作时间考证   ← 考证是独立板块
└─ 版本、辑佚、辨伪

三、作品本体研究
├─ (一) 思想内容
├─ (二) 艺术形式（意象、句法、体制、用典）
├─ (三) 风格与文体特征
└─ (四) 题材分类研究

四、渊源与影响研究
├─ (一) 继承研究：对前代作家／典籍／思想流派的接受
├─ (二) 影响研究：对后世文学 / 对文人
└─ (三) 接受史／传播史（历代评点、选本、域外传播）

五、其他视角（视成果多寡取舍）
├─ 文化学、地域与家族、政治与制度
├─ 比较研究、跨学科研究
└─ 域外汉学、港台研究

六、结语
├─ 已达成的共识
├─ 存在的不足（具体到人和篇，对照四类毛病）
└─ 研究展望  ← 此处即你的选题

参考文献

取舍原则：不是每一节都要有。贾谊篇只有三节（考证 / 本体 / 继承影响），因为成果集中在那三块；陆游篇的两大块是按"古代 / 现当代"切。堆的形状就是你的提纲（见下）。

七、十步 SOP#

步 动作 产出
1 划三条边界（时间／对象／体裁） 一句话选题
2 建检索式，穷尽检索 文献池
3 建台账（含"核心观点一句话"与页码） notes.csv / Zotero 库
4 分堆（先分堆，再定纲——堆的形状就是提纲） 初步分类
5 精读代表性文献 20–30 篇 精读笔记
6 列争议清单（每个问题上的正反观点） 对比表 ← 综述的精华
7 搭三级提纲（三级封顶） 提纲
8 填正文（每段：谁+说什么+依据+关系+我评） 初稿
9 写结语三层（共识／不足／展望=我的选题） 结语
10 校对引文页码、版本、参考文献格式 定稿

第 4 步最容易做反：不要先想提纲再找文献，要先把文献分堆。你的提纲应该长成你文献的形状，而不是你事先设想的形状。 第 6 步是分水岭：争议清单列不出来，综述就只能是文摘性的。

八、写完逐条自查#

  • [ ] 是不是只罗列不评价？（若是，退回文摘性综述，不合格）
  • [ ] 有没有交代统计口径？数字是否可核查？
  • [ ] 有没有写出争议？分歧点是否说清了在哪一层？
  • [ ] 批评是否具体到人和篇，而不是"研究不够深入"这种空话？
  • [ ] 结语的展望是否就是自己的选题？
  • [ ] 古代评点／史料有没有被遗漏？（尤其是通代题目）
  • [ ] 引文是否第一手？古籍是否标了版本 + 页码？
  • [ ] 有没有以论带史（用自己的论文框架硬套学术史）？
  • [ ] 分类是否过碎（超过三级）？
  • [ ] 思潮／外部成因有没有点出？（如"改革开放后研究转向山水、爱情诗"）

更完整的检查见 checklist-ancient-literature.md。
